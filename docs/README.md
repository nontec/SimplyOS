# Документация SimplyOS

Сверено с опубликованным 26.11-Release.26 и App API 1.19, 9 ноября 2026 года. Текущий ISO — 26.11-Release.16. Версии системного пакета, установочного образа, приложения и SDK различаются. Исторический номер Dev в руководстве обозначает появление функции, а не обязательность перехода на Dev сегодня.
