# Накопители и Проводник SimplyOS

В Release.25 и более новых выпусках (начиная с 26.11-Dev.20) Проводник использует общие системные интерфейсы управления накопителями. Команды Linux выполняются системным посредником и отдельным заданием, а не кодом приложения. Существующий API USB для обмена с интерфейсами устройств сохраняется; для файловых систем добавлены методы `devices.storage.*` в том же API устройств.

## Съёмные тома

Контекстное меню тома содержит открытие, изменение названия, форматирование, безопасное извлечение и свойства. Поддерживаются exFAT, NTFS, ext4 и FAT32 при наличии соответствующих утилит. Поддержка устанавливается из подписанного зеркала SimplyOS кнопкой в Проводнике. FAT32 ограничивает размер одного файла и не используется для полного резервного копирования.

Форматирование и переименование требуют пароля администратора. Для форматирования Проводник дополнительно требует ввести путь выбранного устройства. Проверяются текущее дерево разделов, подключённые файловые системы, идентификатор и параметры выбранного тома. Системные разделы, целые диски с разделами и тома, используемые другой учётной записью, не форматируются. Извлечение и отключение выполняются без принудительного или отложенного размонтирования; занятый том остаётся подключённым. Быстрое форматирование не является гарантированным уничтожением прежнего содержимого.

Приложение «Восстановление» показывает подключённые носители, включая ещё не смонтированные. Перед созданием полного бэкапа система подключает выбранный том и проверяет свободное место. Форматирование для резервного копирования автоматически не выполняется.

## Сетевые ресурсы

В Проводнике можно подключить SMB (`smb://сервер/ресурс`), SFTP (`sftp://сервер/путь`) и WebDAV через HTTPS (`https://сервер/путь`). Для SMB используется системный CIFS; SFTP и WebDAV обслуживаются rclone/FUSE от имени текущего Linux-пользователя. Доступ к файлам не выдаётся другим пользователям через allow-other. Для SFTP требуется SHA256-отпечаток SSH-ключа сервера, полученный доверенным способом; ключ проверяется до входа. Проверка HTTPS-сертификата не отключается.

Учётные данные хранятся локально с ограниченными правами до отключения и удаления подключения. Они не передаются приложению из Магазина и не публикуются в отчёте диагностики. Обфускация пароля rclone не заменяет шифрование системного диска. После перезагрузки сохранённый ресурс можно подключить вручную снова. Пароль доменной учётной записи или сервиса следует вводить только для доверенного сервера.

Перед отключением ресурса нужно закрыть документы и дождаться отправки данных. Для rclone проверяются открытые файлы, очередь загрузки и ошибки записи. При аварийном завершении кэш и конфигурация сохраняются; сначала подключите ресурс повторно и завершите отправку. Копирование файлов в сетевую папку не следует считать завершённым на сервере, пока остаётся незавершённая отправка. Сетевые каталоги доступны в общих диалогах открытия и сохранения; содержимое удалённых серверов автоматически не включается в локальный полный бэкап.

Первичные описания транспортов: [SMB/CIFS Linux](https://www.kernel.org/doc/html/latest/admin-guide/cifs/usage.html), [SFTP rclone](https://rclone.org/sftp/), [WebDAV rclone](https://rclone.org/webdav/), [кэш FUSE](https://rclone.org/commands/rclone_mount/).

## App API 1.19

Для списка томов и прогресса своих заданий необходимо разрешение `devices.storage.read`. Для подключения, отключения, форматирования и изменения названия — `devices.storage.manage`. Требуется доверенное приложение; права сверяются с установленным манифестом и списком отозванных разрешений. Изменяющие вызовы работают только из активного окна и требуют отдельного системного подтверждения. Форматирование и переименование дополнительно требуют PAM-подтверждения администратора; приложение пароль не получает.

| Метод | Параметры |
| --- | --- |
| `devices.storage.list` | Нет. Возвращает `devices` и `formatters`. |
| `devices.storage.mount` | `device`, `fingerprint`. |
| `devices.storage.unmount` | `device`, `fingerprint`. |
| `devices.storage.setLabel` | `device`, `fingerprint`, `label`. Возвращает `job_id`. |
| `devices.storage.format` | `device`, `fingerprint`, `filesystem` (`exfat`, `ntfs`, `ext4`, `fat32`), `label`. Возвращает `job_id`. |
| `devices.storage.job` | `job_id`, выданный этому приложению в текущем сеансе серверного процесса. |

```js
const {devices} = await window.simplyos.request('devices.storage.list');
// Выбранный пользователем том из списка, не системный диск:
const volume = devices.find(item => item.path === selectedPath);
await window.simplyos.request('devices.storage.mount', {
  device: volume.path,
  fingerprint: volume.fingerprint
});
const {job_id} = await window.simplyos.request('devices.storage.setLabel', {
  device: volume.path,
  fingerprint: volume.fingerprint,
  label: 'Архив'
});
const progress = await window.simplyos.request('devices.storage.job', {job_id});
```

При замене устройства старый fingerprint отклоняется. API не принимает команды, пути к утилитам и произвольные параметры mount или mkfs. Прямая блочная запись образа этим выпуском ещё не предоставляется; будущая утилита записи образов должна использовать отдельную системную операцию с теми же проверками устройства и подтверждением удаления данных.

Внутренние маршруты оболочки: `GET /api/system/storage`, `POST /api/system/storage` для соединения/отключения сетевого ресурса, существующий `POST /api/system/removable` для томов и административные операции `storage_setup`, `storage_format`, `storage_label`. Мост VPK самостоятельно проверяет права через `/api/vole-apps/{id}/storage`; сторонний пакет не получает административных полномочий от одного объявления разрешения.
