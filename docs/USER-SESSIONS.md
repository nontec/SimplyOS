# Переключение пользователей SimplyOS

Сверено с 26.11-Release.26. Сохранение окон в памяти не заменяет резервную копию и не гарантирует работу системных приложений неактивного пользователя.

При входе под другой учётной записью из экрана блокировки графическая оболочка сохраняет окно прежнего пользователя в памяти и скрывает его. Для нового пользователя открывается отдельное окно оболочки. После возврата и повторного ввода пароля показываются прежние окна, документы и вкладки без их повторного создания.

Оболочки разных пользователей используют отдельные разделы Chromium для файлов cookie, локального хранилища и гостевых сайтов. Права на файлы и системные операции по-прежнему проверяет backend вошедшего пользователя. Во время переключения backend прежнего пользователя останавливается, поэтому сетевые запросы его системных приложений до возврата могут прерываться. Само графическое окно и его состояние остаются в памяти.

Выход из профиля отличается от блокировки: он завершает графический сеанс пользователя и закрывает его окна. После перезагрузки оперативная память очищается; открытые окна не сохраняются этим механизмом. Для переноса рабочего набора между перезагрузками служат «Рабочие пространства».

Если встроенный движок Electron недоступен, система запускает прежнюю оболочку Chromium. В ней переключение пользователей остаётся переключением с перезапуском графической оболочки.
