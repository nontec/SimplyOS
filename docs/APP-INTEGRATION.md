# Применение App API в SimplyOS

Сверено с Release.26, контракт 1.19. В контракте 103 метода; встроенные HTTP-маршруты оболочки не входят в этот перечень.

| Приложения | Интеграция | Возможности и границы |
| --- | --- | --- |
| SimplyVPN | App API и зарегистрированная VPN-служба | Профили, добровольное подключение, статус, остановка; туннель может сохраняться после закрытия окна |
| Торренты | App API и зарегистрированная torrent-служба | Управление загрузками; исполняемые файлы и служба поставляются проверенным пакетом |
| Collabora Writer/Calc/Impress | Локальный движок и WOPI-мост | Документы, выбор файлов, сохранение и печать через предусмотренную интеграцию оболочки |
| Mesh Радио 2.x | Универсальные COM, BLE GATT и TCP | Протоколы Meshtastic/MeshCore реализует приложение; старые mesh.* оставлены для совместимости |
| PeerRing | media.capture, media.call, сетевые каналы, app.data | Медиасогласие, звонки и мини-окно; фоновое окно не является независимой root-службой |
| Telegram/X/VK/MAX/ОК | Установленное приложение и гостевая веб-страница | Уведомления, файлы и разрешения через системную интеграцию; удалённый сервис нужен для содержимого |
| SimplyOS Benchmark | system.hardware.read и ограниченная сеть | Тесты локально; характеристики и баллы публикуются только по согласию |
| SimplyOS Studio | studio.open и комплектный локальный сервис | Работа с проектами и SDK; системные возможности SDK требуют соответствующей версии API |
| Плитки 2048 | Автономное VPK | Для самой игры сетевые и аппаратные разрешения не нужны |
| Стандартные приложения | Внутренние интерфейсы оболочки | Не следует выдавать этот доступ стороннему VPK или считать его частью публичного моста |

Почта — стандартное приложение. Реквизиты IMAP/SMTP хранятся в пользовательском AES-GCM-конверте с ключом, полученным из пароля после PAM-проверки. Это не открытый файл пароля и не шифрование всего диска. При административном сбросе пароля может понадобиться подключение почты заново.

Новые VPK объявляют права в manifest.json, проверяют методы через system.api.info и обрабатывают отзыв разрешений, отмену операции и завершение сеанса. Подписанный источник, доверенный статус, разрешение и согласие пользователя — разные проверки. [Контракт и примеры](API.md) · [Модель доступа](SECURITY-MODEL.md).
