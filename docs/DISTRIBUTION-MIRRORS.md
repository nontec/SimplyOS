# Серверы обновлений и Магазина SimplyOS

С 26.11-Dev.7 клиент знает два адреса обновлений:

- `https://updatesios.nontec.ru/`
- `https://simplyos.ru/updatesios/`

Магазин использует `https://simplyos.ru/market/`, резервный адрес — `https://updatesios.nontec.ru/store/`. Каталог, VPK, иконки, исходники открытых приложений и SDK доступны на обоих серверах. Для старых установок сохраняются прежние адреса. Если сертификат нового домена ещё не настроен или сервер недоступен, клиент использует резервный адрес; проверка TLS не отключается.

Каталог обновлений — `index.json` и `index.json.sig`; каталог Магазина — `catalog.json` и `catalog.json.sig` относительно адреса Магазина. Подпись и соответствующий каталог загружаются с одного зеркала. Пакеты проверяются по размеру и SHA-256 из подписанного каталога. Перенаправление за пределы выбранного HTTPS-узла и его каталога не принимается. Зеркало не получает ключи подписи и не подписывает пакеты самостоятельно.

## Пакеты Linux

- `https://updatesios.nontec.ru/debian/`
- `https://simplyos.ru/updatesios/debian/`

Обновление переводит известные источники SimplyOS на `mirror+file:/etc/apt/mirrors/simplyos.list`. Локальный список принадлежит root; основной сервер имеет приоритет 10, резервный — 20. APT выбирает запасной адрес при недоступности файла на основном. Сохраняются выпуск, компоненты и `Signed-By`, а также посторонние APT-источники. До изменения создаётся копия старого файла с суффиксом `.before-simplyos-mirrors`. Настройка выполняется повторно без дублирования записей.

Механизм `mirror+file` и приоритеты описаны в [документации APT](https://manpages.debian.org/trixie/apt/apt-transport-mirror.1.en.html). Метаданные репозитория проверяются существующим ключом SimplyOS Debian Mirror. Установщик проверяет доступность и подпись зеркала до изменения диска и может выбрать запасной адрес.

## Синхронизация

Зеркало получает только опубликованные файлы через SSH/rsync с доступом на чтение. Пакеты копируются перед каталогами; подписи каталогов SimplyOS и APT проверяются до их публикации. Метаданные APT переключаются между снимками, а не изменяются в процессе раздачи. Таймер синхронизации запускается через пять минут после завершения предыдущей проверки.

HTTPS завершается на внешнем nginx-прокси; сервер зеркала обслуживает HTTP внутри собственной инфраструктуры. На прокси должны маршрутизироваться оба префикса: `/updatesios/` и `/market/`. Публичный сертификат должен соответствовать `simplyos.ru`. Наличие работающего внутреннего HTTP-сервера не означает готовности публичного TLS.
