# Экранная клавиатура и шрифты

Доступно с 26.11-Dev.9. Автоматический вызов включается в «Настройки → Специальные возможности → Экранная клавиатура». Предпочтение сохраняется отдельно для пользователя. При выборе редактируемого поля клавиатура появляется в нижней части экрана. Русская и английская раскладки, Shift, цифры, символы, пробел, удаление, Enter, Tab и перемещение курсора доступны без физической клавиатуры.

Рядом с полями пароля оболочки есть кнопка ручного вызова. В полях встроенного браузера и веб-клиентов доступен пункт контекстного меню «Экранная клавиатура». Ручной вызов не включает постоянное автоматическое появление. Кнопка скрытия закрывает панель; автоматический режим снова показывает её при выборе другого поля. Функция работает в оболочке, встроенном браузере и редакторах с обычными HTML-полями и contenteditable. Приложения с собственным нестандартным вводом через canvas могут не определяться как текстовое поле.

Панель — локальная изолированная часть оболочки Electron. Она не получает содержимое полей, не сохраняет ввод и не отправляет его на сервер. Проверка фокуса возвращает только признак редактируемого элемента и его служебные характеристики. Клавиши передаются только активному полю текущей пользовательской оболочки или принадлежащего ей встроенного приложения. IPC панели проверяет отправителя, активного пользователя и разрешённые типы клавиш. Публичный App API для произвольного ввода текста в чужое приложение не добавляется.

В обновление включены Noto Sans CJK Regular и Bold из пакета Debian fonts-noto-cjk. Поддерживаются китайский, японский и корейский текст, включая системные окна и встроенные приложения. Шрифты устанавливаются локально и регистрируются в fontconfig; отдельное скачивание после загрузки обновления не требуется. Оригинальные лицензии поставляются вместе со шрифтами. Пакет также добавлен в зеркало и список установщика.
