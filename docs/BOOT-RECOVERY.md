# Защита загрузки SimplyOS

Подготовлено для 26.11-Dev.19. Защищается переключение системного выпуска SimplyOS, расположенного в /opt/simplyos/releases, а не весь диск.

Перед изменением сохраняются предыдущий выпуск, контрольные суммы и режимы доступа управляемых конфигураций и вспомогательных программ, а также ссылка на браузерный движок. Точка хранится в /var/lib/simplyos/boot-recovery с доступом только root. Служба восстановления установлена отдельно от current и не заменяется старой копией при откате.

После применения обновления начинается пробная загрузка. Сам интерфейс после завершения своей инициализации сообщает о готовности. Для подтверждения нужны три сообщения с интервалами не менее 8 секунд, поступившие в течение не менее 25 секунд. Вход пользователя не требуется. После подтверждения опрос прекращается.

Если за 210 секунд графическая среда не подтвердилась, независимая служба возвращает сохранённые системные компоненты, отменяет повторное применение того же ожидающего пакета и перезагружает устройство. Если две загрузки прерваны раньше подтверждения, при следующей загрузке выполняется откат. Учёт ведётся по boot_id; перезапуск службы внутри одной загрузки не увеличивает число попыток. Прерванное восстановление продолжается при следующем старте.

## Ручной откат

Во время загрузки меню GRUB показывается на 8 секунд, если точка отката доступна. Выберите SimplyOS - restore previous working version. Используются те же команды загрузки ядра и initrd, что в автоматически сгенерированном пункте Linux, с дополнительным параметром simplyos.rollback=previous. Загрузка шифрованного раздела по-прежнему требует его обычного пароля. Пункт не открывает root-консоль и не отключает Secure Boot.

Генератор установлен как /etc/grub.d/42_simplyos_recovery. Другие пункты загрузки, включая Windows, не заменяются. Описание механизма расширения меню: [GNU GRUB](https://www.gnu.org/software/grub/manual/grub/html_node/Simple-configuration.html).

## Границы восстановления

Возвращаются версия среды SimplyOS и сохранённые управляемые файлы служб. Личные файлы, приложения из Магазина, пароли и пользовательские документы не откатываются. Установленные пакеты APT, ядро Linux, разметка диска, EFI-загрузчики и файловые системы не восстанавливаются. Для этих случаев нужны резервные копии или установочный носитель. Восстановление работает после доступности системного раздела; повреждённый загрузчик или ядро, не доходящее до этой стадии, этим механизмом не исправляются.

Первая новая установка без прежнего выпуска не имеет точки отката. При установке обновления на существующую SimplyOS точка создаётся до изменений. Новый системный выпуск нельзя накладывать поверх ещё не подтверждённого пробного запуска.

## Проверка состояния

В приложении Диагностика есть проверка защиты загрузки и название предыдущего выпуска. Из терминала администратор может выполнить sudo python3 /usr/local/libexec/simplyos-boot-recovery.py status. Запуск rollback из терминала предназначен для обслуживания до запуска пользовательских служб; при работающем рабочем столе используйте загрузочное меню.

Полное восстановление, явно выбранное пользователем, отменяет пробную загрузку; watchdog запускается после службы полного восстановления. Выбор отката из GRUB отменяет противоречащее ему ожидающее полное восстановление. Перед откатом по тайм-ауту состояние повторно проверяется под блокировкой, чтобы не откатить уже подтверждённую версию. Интервалы подтверждения измеряются монотонными часами. После входа в поддерживающую это версию интерфейса показывается уведомление о выполненном восстановлении.
