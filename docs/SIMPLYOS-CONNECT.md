# SimplyOS Connect

Первый выпуск: приложение 1.0.0, системная поддержка 26.11-Dev.27, App API 1.20.

## Установка и подключение

Установите SimplyOS Connect из Магазина. KDE Connect и зависимости автоматически устанавливаются из зеркала SimplyOS вместе с приложением. На телефон установите KDE Connect, подключите оба устройства к одной локальной сети и откройте приложения. Нажмите «Найти устройства», выберите телефон, сверьте ключи и подтвердите сопряжение с обеих сторон. Гостевая сеть и изоляция клиентов Wi-Fi могут препятствовать обнаружению. Соединение использует протокол KDE Connect, собственный облачный сервер SimplyOS не требуется.

Приложение показывает устройства и заряд, позволяет найти телефон звуковым сигналом, передать файл, ссылку или текст. Входящие файлы принимает служба KDE Connect в каталог загрузок. Уведомления и последние сообщения SMS доступны только после разрешения на телефоне и в SimplyOS. Уведомления можно пересылать в Центр уведомлений, включив фоновую работу. Ответы на уведомления зависят от поддержки приложения на телефоне. Полный архив SMS и вложения в этом выпуске не предоставляются. Отправка SMS требует отдельного подтверждения с номером и текстом; оператор может взимать плату. Статус «принято» означает принятие запроса службой, а не подтверждённую доставку.

## Карточка в меню «Пуск»

В «Настройки → Система → SimplyOS Connect» включите карточку, выберите сопряжённое устройство и нужные элементы: заряд, состояние соединения, передача данных, уведомления, SMS, поиск телефона. Карточка встроена в меню, на небольших экранах располагается над приложениями. Выбор видимых кнопок не предоставляет дополнительных разрешений: они открывают приложение, где действия проходят обычные проверки API. До включения карточка скрыта. Настройки сохраняются отдельно для каждой учётной записи. Тексты сообщений и уведомлений в карточке не отображаются.

## Разрешения и служба

Используется универсальное пространство `devices.companion.*`, доступное доверенным приложениям при наличии разрешений манифеста. Магазин не предоставляет обхода проверок. Оболочка пересылает запрос в локальный backend, который проверяет пользователя, Origin, доверие к манифесту, установку и отозванные разрешения. Чувствительные операции подтверждаются в системном окне. Одноразовый билет действителен 60 секунд и привязан к приложению, пользовательскому сеансу, установке и ключу устройства. Перед выполнением права и ключ проверяются повторно. Для чтения уведомлений и SMS согласие можно сохранить; повторное сопряжение или отзыв разрешений его отменяет. Содержимое SMS передаётся через типизированный D-Bus, без аргументов командной строки.

Установщик от root проверяет установленный бинарник KDE Connect и закрепляет его SHA-256 в конфигурации службы. Запуск проверяет эту сумму, сохраняя `ProtectSystem=full` и `NoNewPrivileges`; при изменении бинарника Магазин предлагает восстановить компоненты.

Локальная пользовательская служба `simplyos-connect.service` запускается при обнаружении устройств, работает без root и не включается автоматически при установке. При сопряжении используется ограниченный набор модулей: заряд, поиск телефона, передача данных, уведомления, SMS. Управление командами, удалённый ввод и SFTP приложением не включаются. Настройки сторонней службы, изменённые пользователем вручную вне SimplyOS, не охватываются этим ограничением. Приложение не сохраняет тексты SMS и уведомлений в своём файле настроек; собственный кэш KDE Connect может содержать данные телефона.

## API

| Методы | Разрешение |
|---|---|
| status, list, device | devices.companion.read |
| discover, pair, unpair | devices.companion.pair |
| ring | devices.companion.control |
| shareText, shareUrl, shareFile | devices.companion.share |
| notifications.list | devices.companion.notifications.read |
| notifications.reply, notifications.dismiss | devices.companion.notifications.control |
| sms.conversations | devices.companion.sms.read |
| sms.send | devices.companion.sms.send |

Все методы имеют префикс `devices.companion.`. `deviceId` получайте из `list`. `shareFile` принимает только `deviceId`: файл выбирается в системном диалоге, приложение не передаёт произвольный путь. Методы чтения уведомлений и SMS имеют `offset` и `nextOffset`; это снимок текущего кэша службы, а не поток истории. Подробные типы и обёртки — `companions.d.ts` и `companions.js` SDK 0.3.0.

```js
const {devices} = await window.simplyos.request('devices.companion.list');
const phone = devices.find(d => d.paired && d.reachable);
if (phone) {
  await window.simplyos.request('devices.companion.shareFile', {deviceId: phone.id});
}
```

Чтение status/list/device, notifications.list и sms.conversations допускается в фоне по действующим разрешениям; согласие на новую чувствительную цель необходимо получить, пока окно открыто. Мутации из скрытого окна не выполняются без системного подтверждения. Для получения уведомлений приложение должно продолжать фоновую работу: завершённое приложение их не обрабатывает.

Трансляция экрана телефона, голос телефонных разговоров через ПК и синхронизация буфера обмена пока не реализованы. Совместимость зависит от версии и разрешений KDE Connect на телефоне. Протокол и ограничения проверяются автоматическими тестами; физическое сопряжение с конкретной моделью телефона требует отдельной проверки.

## Сторонний компонент

KDE Connect распространяется с сохранением авторства и лицензий. [Соответствующий пакет исходников KDE Connect 25.04.2-1+deb13u1](https://simplyos.ru/market/apps/ru.simplyos.connect/kdeconnect-25.04.2-1+deb13u1-source.zip) содержит исходный архив, подпись и упаковку Debian. SHA-256 архива включён в подписанный каталог Магазина в `thirdPartySources`. Сведения об авторах и лицензиях входят в пакет приложения и в `/usr/share/doc/kdeconnect/copyright`. SimplyOS Connect не является официальным клиентом KDE.

## Изменения 26.11-Dev.28

SimplyOS Connect 1.0.1 исправляет запуск в изолированном окне. После удаления приложения его раздел настроек и карточка телефона в меню «Пуск» скрываются без перезагрузки. Параметры карточки сбрасываются. Исправлены значок раздела и вертикальное расположение настроек в небольшом окне.

При удалении приложения система останавливает принадлежащую ему службу и удаляет системные пакеты, установленные для него Магазином, если они больше никому не нужны. Общие компоненты, ранее установленные пакеты и зависимости других пользователей сохраняются. Личные документы и загрузки не удаляются.

При сбое установки Connect с запросом о `coolwsd.xml` требуется системное обновление 26.11-Dev.29: оно исправляет завершение ранее прерванной настройки пакетов. Это не ошибка протокола связи с телефоном.
