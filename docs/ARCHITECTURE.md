# Архитектура SimplyOS

Сверено с SimplyOS 26.11-Release.26, App API 1.19, 9 ноября 2026 года. Система использует ядро Linux и пакетную базу Debian GNU/Linux 13. Vole — кодовое имя выпуска.

## Состав

| Уровень | Компоненты | Назначение |
| --- | --- | --- |
| Базовая система | Linux, Debian 13, systemd, NetworkManager, PipeWire, CUPS | Драйверы, процессы, сеть, звук и печать |
| Графическая сессия | greetd, Wayland, labwc | Запуск экрана входа и графической среды |
| Оболочка и встроенный браузер | Electron, Chromium, TypeScript, HTML, CSS | Окна, рабочий стол, настройки; сайты в гостевых webview с исходным адресом |
| Пользовательский backend | Python, FastAPI | Файлы, события, приложения и внутренние локальные HTTP-интерфейсы |
| Привилегированный посредник | voleos-auth.service, PAM, фиксированные помощники | Подтверждаемые административные операции и системные задания |
| VPK-приложения | Локальные HTML-пакеты и ограниченный мост App API | Работа по доверенному статусу, манифесту и не отозванным разрешениям |
| Офис | Локальный Collabora Online и WOPI-мост | Редактирование документов, таблиц и презентаций |

В Release.26 поставляется Electron 45.2.3 с Chromium 156.0.8078.80 и Node.js 24.22.2. Обновление Debian-пакета Chromium не заменяет отдельный движок Electron. Бинарные файлы Electron входят в подписанный USP; гостевые сайты не получают Node.js API или мост приложений SimplyOS.

## Запуск и пользовательские данные

Активный выпуск находится в `/opt/simplyos/releases/<версия>`; `/opt/simplyos/current` — ссылка на него. Пользовательский backend обслуживает loopback-порт 8765. Экран входа доступен до PAM; пользовательские данные и операции требуют действующего сеанса.

Служебная учётная запись `simplyos-shell` запускает графическую оболочку и не является владельцем личных файлов пользователя. После входа файловые операции выполняются в контексте выбранной учётной записи. Профили Chromium разных пользователей разделены. Смена пользователя сохраняет скрытое окно прежней оболочки в памяти, но не гарантирует непрерывную фоновую работу прежнего backend. [Переключение пользователей](USER-SESSIONS.md).

Если комплектный Electron отсутствует, стартовый скрипт допускает прежнюю оболочку Chromium как резервный путь. Этот режим не предоставляет одинаковых возможностей встроенного браузера и сохранения графических сеансов. [Устройство браузера](BROWSER-ENGINE.md).

## Границы системных интерфейсов

Встроенные компоненты используют внутренние HTTP-интерфейсы. Доверенный VPK получает `window.simplyos.request()`: оболочка сопоставляет фактическое окно, capability сеанса, MessagePort, установленный манифест и отзыв прав. Для чувствительных операций backend повторяет проверку разрешений, владельца и цели. JSON-контракт описывает правила, но сам их не исполняет.

Недоверенные VPK и обычные сайты не получают этот мост. Привилегированный посредник принимает только предусмотренные операции, проверяет клиента и PAM там, где требуется административное подтверждение. Произвольная команда из HTML не является допустимой административной операцией. Python-компонент VPK — отдельная ограниченная функция приложения, не root-shell. [Модель доступа](SECURITY-MODEL.md) · [API](API.md).

## Поставка и восстановление

Системный USP содержит среду SimplyOS, собранный интерфейс, Python-зависимости и предусмотренные комплектные компоненты. Приложения Магазина поставляются отдельно. Клиент проверяет подписи каталогов, размеры и SHA-256 загрузок. В Release.26 Магазин и обновлятор не следуют автоматическим HTTP-перенаправлениям.

Linux-пакеты поступают из подписанного зеркала SimplyOS. Сервер зеркала получает подготовленный набор из исходных репозиториев; это не прямое обращение пользовательской системы к Debian. [Каналы распространения](DISTRIBUTION-MIRRORS.md).

Защита загрузки возвращает предыдущую среду и сохранённые управляемые файлы. Она не откатывает ядро, пакеты APT, разметку и личные документы. Полная резервная копия и перенос рабочих пространств — отдельные механизмы. [Обновления и восстановление](UPDATES-AND-RECOVERY.md).

## Границы защиты

HTML-песочница и Linux-права не равнозначны независимому контейнеру для произвольного нативного кода. Процессы одной учётной записи имеют общие ограничения этой модели. Шифрование диска и Secure Boot зависят от установки и настроек, а не автоматически включаются системным обновлением. [Опубликованный аудит](https://simplyos.ru/security/).
