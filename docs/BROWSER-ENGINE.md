# Встроенный браузер SimplyOS

Сверено с Release.26. Основной путь — Electron с гостевыми Chromium webview внутри окон SimplyOS. Сайт сохраняет исходный адрес и напрямую исполняется движком; изображение страницы не кодируется в JPEG и не передаётся через backend.

## Окна, профили и изоляция

Вкладки, адресная строка, история и управление окнами принадлежат интерфейсу SimplyOS. Сайты работают в отдельных гостевых страницах без Node.js и системного моста VPK. Профили разных пользователей разделены. Старые proxy/headless-модули в исходном дереве не являются основным способом отображения сайтов.

В Release.26 используется Electron 45.2.3 / Chromium 156.0.8078.80 / Node.js 24.22.2. Комплектный движок обновляется системным USP отдельно от Debian Chromium. Если Electron недоступен, стартовый скрипт допускает прежнюю оболочку Chromium, но она не даёт эквивалентной функциональности браузера и сохранения графических сеансов.

## Загрузка и отправка файлов

Скачивание отслеживается событиями движка: интерфейс показывает байты, состояние и фактическое имя результата. Сначала используется отдельный временный каталог, затем файл передаётся в область пользователя через системный маршрут. Совпадение имени не должно незаметно заменять существующий файл: результат возвращает фактическое имя, путь и размер.

Для веб-клиентов Telegram/X перед сохранением открывается системный выбор папки и имени. Отмена прекращает загрузку; этот диалог не требует открытого окна браузера. События содержат appId, чтобы не показывать загрузку одновременно во всех окнах.

Отправка файла на сайт начинается с явного выбора пользователя. Гостевая страница получает только выбранные данные. Современный потоковый маршрут браузера не имеет прежних ограничений proxy-портала 64/100 МБ; свободное место, временное хранение и ограничения конкретного сайта по-прежнему учитываются.

## Разрешения и буфер обмена

Камера, микрофон и другие возможности сайта проверяются через системную интеграцию. Для установленных веб-клиентов согласие сайта не заменяет действующее разрешение приложения. При отзыве медиадоступа в Release.26 гостевое окно перезагружается для прекращения потоков; профиль авторизации сохраняется. Политика не выдаёт доступ при недоступности её проверки.

Collabora использует локальный iframe с явной делегацией clipboard-read/clipboard-write адресам локального движка. Это отдельный путь от внешних сайтов; удалённой странице не предоставляется Node.js для работы с буфером. [Модель доступа](SECURITY-MODEL.md).

## Медиа и системная интеграция

Поддерживаемые страницы публикуют состояние воспроизведения в общий реестр медиасессий. В центре уведомлений видна одна карточка; несколько проигрывателей переключаются горизонтально. Полноэкранное видео должно завершать собственный режим по Esc, сохраняя оболочку. [Медиасессии](MEDIA-SESSIONS.md).

Контекстное меню, выбор файлов и скачивания интегрированы с SimplyOS. Профиль сохраняет вход на сайты между запусками; рабочие пространства переносят безопасно обработанные адреса вкладок, а не cookie и пароли.

## Ограничения

Наличие Chromium не гарантирует работу каждого сайта, DRM-контента, кодека, расширения или аппаратного ускорения. Авторизация, push/уведомления и поведение веб-клиентов зависят также от самого сервиса. Проверки на конкретных устройствах и сложных сайтах продолжаются. В VirtualBox/VMware/Hyper-V стартовый скрипт может отключать GPU для совместимости; на физических компьютерах путь выбирается отдельно.
