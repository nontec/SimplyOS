# Персонализация

В текущем Release (начиная с 26.11-Dev.10) темы, акценты и фоны выбираются визуально, без дублирующих выпадающих списков. Предпросмотр показывает тему окон, нижнюю панель, акцент и тот же фон, который используется рабочим столом. Для сохранения выбора нажмите «Применить».

Карандаш в углу однотонного фона открывает выбор цвета. Кнопка своего изображения добавляет копию выбранного файла в ~/.local/share/simplyos/wallpapers внутри текущего профиля. Исходный файл остаётся на месте; его последующее перемещение или удаление не влияет на сохранённые обои.

Коллекция показывает до шести последних изображений. Более старые сохранённые копии удаляются автоматически; копия текущего применённого фона сохраняется, пока пользователь не применит новый фон. При применении нового оформления лишние копии удаляются. Кнопка удаления на миниатюре удаляет сохранённую копию и запись коллекции, сохраняя исходный файл. Если удалены текущие обои, выбирается стандартный фон «Северное сияние».

Папка и история принадлежат текущему пользователю. Удаление через интерфейс принимает только имена сохранённых изображений из этой коллекции и не удаляет произвольные пользовательские файлы.

С 26.11-Dev.11 миниатюры пользовательских обоев загружаются как статичные JPEG до 240×150, предпросмотр — до 640×400. Они создаются отдельным ограниченным по ресурсам процессом и сохраняются в подкаталоге .previews коллекции обоев. Полноразмерный оригинал используется самим рабочим столом. Миниатюры удаляются вместе с сохранённой копией. Выбор нового изображения выполняется плиткой «Своё изображение»; повторная кнопка под коллекцией убрана.

Минимальная яркость экрана — 5%. Ограничение применяется службой, ползунком, Fn-клавишами и при восстановлении прежних настроек.
