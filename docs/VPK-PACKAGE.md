# Формат пакета приложения SimplyOS

Сверено с Release.26 и App API 1.19. `formatVersion: 1` обозначает формат контейнера, а не версию API.

Пакет SimplyOS — ZIP-архив с расширением `.vpk` (установщик также принимает `.zip`). Установка распаковывает веб-файлы в профиль пользователя. Обычный VPK не запускает скрипты установки и не устанавливает Debian-пакеты. Для официальных приложений, которым нужны системные файлы, применяется отдельный фиксированный установщик компонентов SimplyOS; произвольный код из VPK ему не передаётся.

## Структура архива

```text
manifest.json
index.html
app.js
styles.css
icons/app.svg
```

`manifest.json` должен находиться в корне архива. Минимальный пример:

```json
{
  "format": "vole-app",
  "formatVersion": 1,
  "id": "org.example.notes",
  "name": "Заметки",
  "appVersion": "1.0.0",
  "entry": "index.html",
  "icon": "icons/app.svg",
  "permissions": []
}
```

| Поле | Назначение |
| --- | --- |
| `format` | Всегда `vole-app`. |
| `formatVersion` | Версия формата, сейчас `1`. |
| `id` | Постоянный ID: строчные латинские буквы, цифры, точки и дефисы; 3–80 символов. |
| `name` | Название, не длиннее 80 символов. |
| `appVersion` | Версия приложения для отображения. |
| `entry` | Относительный путь HTML-точки входа внутри архива. |
| `icon` | Необязательный относительный путь к SVG-иконке. |
| `permissions` | Список запрашиваемых разрешений из [контракта API](API.md). Неизвестные имена отклоняются. |
| `networkHosts` | Необязательный список до 20 точных сетевых узлов для `network.http` и `network.http.private`, например `api.example.org` или `10.0.0.20:8443`. |
| `developer` | Необязательное имя разработчика, показываемое в настройках приложения. |

Соберите архив так, чтобы `manifest.json` лежал непосредственно в корне, а не во вложенной папке. Переходы `..`, абсолютные пути, обратные слеши, символические ссылки и повторяющиеся имена файлов запрещены. Фиксированного ограничения размера пакета нет: для загрузки и установки должно хватать свободного места на диске. В архиве допускается не более 2 000 файлов.

## Среда выполнения и доверие

Приложение открывается в Chromium iframe с ограничениями `allow-scripts allow-forms`. Оно не получает доступ к терминалу и привилегированному API Linux. Недоверенный пакет не получает мост `window.simplyos`; доверенный получает только заявленные и не отозванные разрешения. Для неизвестного источника переключить статус на доверенный можно не раньше чем через 24 часа после установки; автоматически доверие не выдаётся.

Официальный магазин проверяет подпись каталога и SHA-256 пакета, скачивает все файлы VPK для локальной работы и показывает минимальную версию SimplyOS до установки. Подпись подтверждает источник и целостность, но не выдаёт разрешения автоматически. Подробности: [модель безопасности](SECURITY-MODEL.md) и [API приложений](API.md).


## Автозапуск приложений

В App API 1.13 добавлены `autostart.get` и `autostart.set`. Приложение объявляет поддержку в манифесте:

```json
{
  "supportsAutostart": true,
  "permissions": ["autostart.manage"]
}
```

Это фрагмент манифеста, дополняющий обязательные поля пакета. По умолчанию автозапуск выключен. Настройка хранится отдельно для пользователя и идентификатора приложения; предоставление доверия не включает её автоматически. При входе приложение запускается в фоне. Самостоятельный запрос на изменение требует подтверждения пользователя; получить состояние можно через `await window.simplyos.request('autostart.get')`, изменить — через `await window.simplyos.request('autostart.set', {enabled: true})`. Ответ содержит `supported`, `enabled`, `native`, `mode` и `requiresAdmin`.

Настройка доступна также в «Настройки → Приложения → сведения о приложении». Недоверенные приложения не запускаются автоматически. Изменение автозапуска не завершает уже работающий процесс и не предоставляет дополнительных разрешений. Разрешение `autostart.manage` позволяет управлять собственной настройкой, а не произвольными приложениями.

Для официального приложения «Торренты» поддержка службы зарегистрирована системой и доступна также ранее установленному пакету. Настройка изменяет только `simplyos-torrent@<пользователь>.service` через PAM-подтверждение и фиксированный системный посредник. Запуск происходит при включении устройства; обычный запуск или остановка службы не меняет автозапуск. Обновление компонентов сохраняет состояние enabled/disabled. Передавать API имя systemd-юнита или команду запуска нельзя. Обычное приложение не может выдать себя за зарегистрированную службу.
