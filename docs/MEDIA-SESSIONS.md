# Медиасессии SimplyOS

Доступно с SimplyOS 26.11-Dev.10, App API 1.16. Медиасессия связывает приложение с проигрывателем в центре уведомлений. Одновременно видна одна карточка; свайп, перетаскивание и точки под ней переключают открытые проигрыватели. Музыка, Видео, встроенный браузер и веб-клиенты используют общий реестр и один компонент интерфейса.

## Разрешение и методы

В манифест VPK добавляется разрешение `media.session`. Методы доступны доверенным приложениям, в том числе в свёрнутом окне. Пользователь может отозвать разрешение в настройках приложений.

| Метод | Назначение |
| --- | --- |
| media.session.update | Создать или обновить сессию текущего окна |
| media.session.actions | Получить и очистить очередь команд пользователя |
| media.session.clear | Удалить свою сессию |

У update обязательны title (до 200 символов) и playing (boolean). Дополнительно: artist (до 200 символов), artwork (HTTPS-адрес или data URL PNG/JPEG/WebP до 200000 символов), position и duration в секундах, actions. Разрешённые действия: play, pause, previoustrack, nexttrack, seekto. По умолчанию доступны play и pause. Перемотка показывается только при положительной конечной duration и действии seekto. Длительность ограничена семью сутками. Неизвестные действия и некорректные значения отклоняются. Состояние рекомендуется обновлять раз в секунду и при изменении воспроизведения; лимит — 180 обновлений в минуту на приложение.

Пример для HTML-проигрывателя:

```javascript
const audio = document.querySelector('audio');
async function publish() {
  await window.simplyos.request('media.session.update', {
    title: 'Название записи', artist: 'Исполнитель',
    playing: !audio.paused,
    position: audio.currentTime,
    duration: Number.isFinite(audio.duration) ? audio.duration : 0,
    actions: ['play', 'pause', 'seekto']
  });
}
const timer = setInterval(async () => {
  const {actions} = await window.simplyos.request('media.session.actions');
  for (const command of actions) {
    if (command.action === 'play') await audio.play();
    if (command.action === 'pause') audio.pause();
    if (command.action === 'seekto') audio.currentTime = command.position;
  }
  await publish();
}, 1000);
audio.addEventListener('ended', async () => {
  clearInterval(timer);
  await window.simplyos.request('media.session.clear');
});
```

Очередь ограничена 32 командами и относится к конкретному сеансу окна. Приложение само выполняет команды и публикует новое состояние. Если проигрыватель не поддерживает предыдущую/следующую запись, эти действия не объявляются, а кнопки недоступны. Сессии не сохраняются после завершения приложения или перезагрузки.

## Принуждение прав и изоляция

Обработчик моста проверяет origin, реальное окно-отправитель, capability, доверие и разрешения по установленному манифесту. Идентификатор владельца генерирует оболочка; appId или чужой идентификатор из payload не принимаются. Обновление, очистка и чтение команд относятся только к окну-отправителю. При смене capability создаётся новый владелец и удаляются прежняя сессия и очередь. Закрытие окна, отзыв доверия или разрешения удаляют карточку; перед управлением проверяется действительность её владельца. Название и исполнитель выводятся как текст.

Веб-сайты не получают App API. Адаптер встроенного движка принимает сведения только от принадлежащих оболочке webContents/frame и привязывает их к этому источнику. Для обычных страниц используются Media Session и HTML audio/video; для вложенных проигрывателей — доступные HTML-медиаэлементы. Команды из центра уведомлений принимает только активная пользовательская оболочка и направляет только исходному фрейму. У стороннего плеера со своим вводом, WebAudio или нестандартной реализацией часть действий может быть недоступна. Поддержка медиа не отключает sandbox, webSecurity или изоляцию сайта.
