# Установка SimplyOS 26.11-Release.16

Установочный ISO — сетевой: требуется доступ к инфраструктуре SimplyOS. Для компьютеров x86-64 поддерживаются UEFI и BIOS. Рекомендуется от 4 ГиБ ОЗУ и от 32 ГиБ на диске. В VirtualBox подходит Debian (64-bit), VMSVGA; 3D-ускорение специально включать не требуется.

## Подготовка

Скачайте ISO, сравните SHA-256 и проверьте подпись файла контрольной суммы по руководству VERIFY-ISO.md. Сохраните важные данные перед изменением разметки. Запишите ISO на USB или подключите его к виртуальной машине. Выберите загрузку с этого носителя.

## Способы установки

В режиме «Очистить весь выбранный диск» существующие разделы выбранного накопителя удаляются. Этот режим доступен в UEFI и BIOS. После проверки сети выберите диск, создайте учётную запись, проверьте сведения и подтвердите очистку вводом пути диска.

Режим «Рядом с другой ОС» доступен при загрузке установщика в UEFI, для GPT-диска с существующим EFI-разделом FAT32. Можно использовать не менее 18 ГиБ неразмеченного места или освободить место внутри NTFS/ext4-раздела. Рекомендуется выделить больше места под приложения и файлы.

Если свободное место находится внутри существующего раздела, нажмите «Найти разделы для уменьшения». Проверка не меняет диск. Выберите подходящий раздел, укажите объём для SimplyOS в ГиБ и проверьте размеры до и после изменения. Установщик оставляет запас свободного места для другой ОС. Подтвердите, что резервная копия важных файлов сохранена, затем проверьте план на последнем экране. Не выключайте устройство во время уменьшения.

Автоматически уменьшаются только отключённые разделы NTFS и ext4 (для ext4 — блок 4096 байт), прошедшие проверку. BitLocker, LUKS, LVM, служебные и recovery-разделы, смонтированные тома и файловые системы с ошибками не уменьшаются. Для NTFS полностью завершите Windows, отключите быстрый запуск и устраните ошибки через chkdsk при необходимости. После уменьшения Windows может выполнить штатную проверку диска. Копия таблицы разделов и план сохраняются в /var/log/simplyos-installer; это не заменяет резервную копию файлов.

Выберите диск, режим установки рядом и свободную область. Будут созданы новые /boot и системный раздел; существующие разделы и файлы в них не форматируются. Общий EFI-раздел используется без форматирования: загрузчик SimplyOS размещается в EFI/SimplyOS. Загрузчики других ОС и резервный EFI/BOOT не заменяются. Для найденных на этом EFI-разделе Windows и Linux-загрузчиков создаются пункты меню GRUB. Существующие записи прошивки также остаются доступными. Для BIOS/MBR совместная установка этим мастером не предусмотрена.

Если на выбранном EFI-разделе уже имеется EFI/SimplyOS, совместная установка прекращается до изменения разметки, чтобы не заменить загрузчик предыдущей SimplyOS. Нужен другой диск или осознанная подготовка разделов вне установщика.

## Secure Boot

UEFI-образ и новая UEFI-установка используют Microsoft-подписанный Debian shim, Debian-подписанный GRUB и подписанное ядро Debian из зеркала SimplyOS. Прошивка должна доверять соответствующему Microsoft UEFI CA для сторонних загрузчиков. Пользовательский ключ SimplyOS для проверки ISO не является ключом Secure Boot и не регистрируется в прошивке.

Внешние DKMS-модули, в частности часть драйверов Wi-Fi, могут требовать регистрации ключа MOK через MokManager. Поддержка загрузки Secure Boot сама по себе не означает, что любой сторонний модуль будет принят ядром. Не отключайте проверку подписей ради установки драйвера; используйте документированную процедуру регистрации ключа. Установка пакета обновления поверх старой системы сама по себе не преобразует её прежний загрузчик в подписанный.

## Шифрование и завершение

На шаге учётной записи можно включить LUKS2-шифрование только нового системного раздела. EFI и /boot остаются открытыми. Сохраните пароль: при его потере доступ к данным восстановить нельзя. Эта опция не шифрует разделы другой ОС.

После завершения извлеките носитель и перезагрузитесь. Войдите в SimplyOS и проверьте Центр обновлений. Release — основной канал; переход в Dev сопровождается предупреждением и запросом пароля администратора.
