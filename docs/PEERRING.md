# PeerRing для SimplyOS

Самостоятельное локальное VPK-приложение для существующего сервиса peerring.ru. Не открывает сайт во внешнем окне и не транслирует изображение браузера. Интерфейс, JavaScript, иконка и Material-иконки входят в пакет.

Возможности: временный код, копирование ссылки, аудио- и видеозвонки, подтверждение входящих до захвата устройств, отклонение, отключение камеры/микрофона/звука, полноэкранное видео, диагностика задержки и кадров, локальная история до 50 звонков, режим TURN-only, работа в трее. Требуется App API 1.18.

После запуска нажмите «Включить приём звонков» и разрешите соединение с peerring.ru. Передайте код собеседнику. Камера и микрофон запрашиваются при исходящем звонке или принятии входящего. Положительные согласия запоминаются, отзыв выполняется в настройках приложений. При закрытии окна в режиме фона звонки продолжают приниматься до выхода из приложения/сеанса ОС. После перезапуска приложение не начинает прослушивание без действия пользователя.

Персональные настройки и история хранятся через app.data текущего пользователя; аудио, видео, SDP и ICE в историю не записываются. Код временный и не является подтверждением личности. Контакты и учётные записи серверным протоколом не предусмотрены. Обмена текстовыми сообщениями из отдельного chat-сервиса в этой версии нет.

Проверено: два тестовых клиента с синтетическими камерой и микрофоном через настоящий WSS; передача декодируемых видеокадров, отдельный TURN-only вызов, завершение и повторный аудиозвонок, отсутствие захвата до принятия, запоминание согласия, остановка исходного захвата при отзыве. Физические устройства и звонок на мобильный APK требуют отдельной проверки.

Для использования установите 26.11-Dev.18 или более новый совместимый выпуск, затем PeerRing из Магазина SimplyOS.

Версия PeerRing 1.1.0 добавляет мини-окно активного звонка при сворачивании приложения. Оно показывает видео собеседника, перемещается по экрану и раскрывает кнопки завершения звонка и возврата в приложение по нажатию. На экране блокировки видео скрыто. Звук остаётся у основного звонка. Используется общее разрешение media.call и API presentCall.

PeerRing 1.1.1 исправляет отображение Material Design иконок в основном окне: SVG включены непосредственно в интерфейс вместо внешних масок. Заголовок экрана звонков заменён на «Аудио- и видеозвонки». Это обновление приложения из Магазина; нового системного обновления не требуется.
