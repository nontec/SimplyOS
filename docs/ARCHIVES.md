# Работа с архивами в проводнике SimplyOS

Доступно в 26.11-Release.25 и более новых выпусках (впервые в Dev.22).

Архив открывается двойным нажатием как отдельное представление внутри окна проводника. Кнопка «К файлам» возвращает к исходной папке. Содержимое не распаковывается целиком только для просмотра списка.

## Форматы и операции

| Формат | Просмотр и распаковка | Создание и изменение |
| --- | --- | --- |
| ZIP | Да | Да |
| 7z | Да | Да |
| TAR, TAR.GZ, TAR.BZ2, TAR.XZ | Да | Да |
| TGZ, TBZ2, TXZ | Да | Да, как соответствующий TAR |
| RAR | Да | Нет |

В архиве доступны переходы по папкам, поиск в текущей папке, выбор нескольких элементов с Ctrl/Shift и выделение всех через Ctrl+A. Можно распаковать весь архив или выбранные элементы в новую папку, добавить файлы или папку, создать папку внутри архива, переименовать или удалить выбранные элементы. Проверка целостности читает содержимое архива, включая проверку контрольных сумм, которую предоставляет его формат.

Контекстное меню проводника содержит создание архива из выделенных файлов и папок, просмотр и распаковку архива. Кнопка создания без выделения упаковывает содержимое текущей папки; это явно указано перед подтверждением. Место сохранения выбирается через системное окно выбора файла. При создании доступны формат, уровень сжатия и необязательный пароль для ZIP/7z. Для ZIP с паролем используется AES-256, для 7z также шифруются имена. Некоторые сторонние архиваторы не поддерживают ZIP AES.

Двойное нажатие на файл внутри архива открывает его извлечённую копию в обычном приложении SimplyOS. Копия хранится в пользовательском кэше `.cache/simplyos/archive-preview`. Изменения этой копии не записываются в архив автоматически: сохранённый файл нужно добавить обратно с разрешением замены. Проводник сообщает об этом при открытии.

Пароль запоминается только на время открытого представления архива. Он не сохраняется в настройках, журнале операций или командной строке 7-Zip. Повторный ввод доступен через кнопку «Пароль».

## Выполнение и защита данных

Операции выполняются от имени текущего пользователя без прав root. Сохраняются ограничения файлового API: домашняя папка и подключённые доступные пользователю накопители. Длительные операции работают в фоновых заданиях, окно показывает текущий этап. Для этапов с известным числом элементов выводится прогресс; внешнее сжатие 7-Zip отображается как выполняющийся этап без выдуманного процента.

Изменение архива сначала выполняется во временной папке на том же накопителе. Новый архив проверяется и затем заменяет исходный файл. При ошибке исходный архив сохраняется. Одновременное изменение исходного файла проверяется по его ревизии. Создание и распаковка не перезаписывают уже существующий файл или папку назначения; атомарное создание не требует поддержки жёстких ссылок, поэтому подходит и для FAT/exFAT.

Пути с выходом из папки распаковки, абсолютные пути, повторяющиеся имена, ссылки и специальные файлы отклоняются. Перед распаковкой проверяется свободное место. Защитный предел составляет 100 000 элементов и 64 ГиБ распакованного содержимого. Самораспаковывающиеся и многотомные архивы в эту реализацию не входят.

## Системный интерфейс

Это внутренний интерфейс проводника. Новое разрешение для сторонних приложений или обход общего моста SimplyOS не добавляются. Маршруты `/api/files/` защищены общей проверкой системной сессии и источника запроса.

`POST /api/files/archive/list` принимает `path` и необязательный `password`. Ответ содержит `format`, `entries`, `revision`, `editable`, `encrypted`, `size`, `unpacked_size`. Поля элемента: `name`, `directory`, `size`, `compressed`, `encrypted`.

`POST /api/files/archive/jobs` запускает задание и возвращает `id`. Поддерживаемые `action`: `create`, `extract`, `add`, `delete`, `rename`, `mkdir`, `test`, `open`. Общие поля: `path`, `revision`, `password`. Дополнительные поля: `destination`, `paths`, `members`, `prefix`, `name`, `overwrite`, `level` (0–9).

`GET /api/files/archive/jobs/{id}` возвращает `state` (`running`, `done`, `error`), `message`, `progress` (число либо `null`), а после завершения — `result` или код ошибки `code`. Повторная попытка изменения после конфликта требует обновить список и получить новую `revision`. История завершённых заданий доступна в памяти службы до часа; паролей в ней нет. После перезапуска службы задания не возобновляются автоматически.

Для совместимости сохранены `GET /api/files/archive?path=…` и синхронный `POST /api/files/archive` для прежних операций создания/распаковки. Новый интерфейс проводника использует фоновые задания. Для 7z, RAR и защищённых ZIP требуется системный компонент 7-Zip, уже включённый в список пакетов установщика SimplyOS.
