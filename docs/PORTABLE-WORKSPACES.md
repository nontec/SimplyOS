# Переносимые рабочие пространства

Откройте «Рабочие пространства» из меню приложений и нажмите «Сохранить текущий набор». Укажите имя. SimplyOS запомнит открытые окна, их положение, вкладки встроенного браузера и пути открытых документов. Сохранённый набор доступен после перезагрузки в учётной записи того же пользователя. Кнопка «Закрыть текущий набор» закрывает окна, не удаляя сохранённую запись.

Для переноса нажмите «Экспорт», задайте пароль длиной не менее 12 символов и выберите внешний накопитель. SimplyOS включает в файл `.sws` открытые документы поддерживаемых форматов общей величиной до 32 МБ. Экспорт шифруется в браузере ключом из пользовательского пароля. Пароль не отправляется серверной части ОС и не записывается в файл. На другом устройстве откройте «Рабочие пространства», нажмите «Импортировать», выберите `.sws` и введите пароль. Импортированные документы будут сохранены в `Документы/Imported Workspaces`, затем рабочее пространство появится в списке.

Встроенный браузер сохраняет адреса вкладок без параметров запроса, фрагментов и учётных данных. Страницы входа и адреса, похожие на ссылки с ключом, открываются с главной страницы сайта. Сеансы сайтов, пароли, cookie и активное VPN-подключение не переносятся. Приложение, которого нет на другом устройстве, нужно установить из Магазина; до этого его окно будет пропущено. Стандартные приложения используют внутренний механизм сохранения состояния; Collabora Writer, Calc и Impress передают оболочке путь текущего документа. Стороннее приложение должно использовать `workspace.state.save` и `workspace.state.load` через разрешение `workspace.state`. Обычное открытие приложения не переносит его внутреннюю базу данных.

Перед переключением пространства сохраните изменения в документах. Для текстового редактора и рисовалки операция блокируется при несохранённых изменениях. Для Collabora новое непустое содержимое нужно сохранить перед созданием пространства; пустой новый документ откроется снова пустым. При закрытии Collabora используется обычное подтверждение сохранения. Поддерживаются текстовые документы, PDF, DOCX/XLSX/PPTX и ODF; большие файлы и мультимедиа в `.sws` не включаются. Фото, музыка и видео на другом устройстве открываются только если там доступен тот же путь к файлу.
