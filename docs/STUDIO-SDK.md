# SimplyOS Studio и SDK

SDK и SimplyOS Studio 0.3.0 содержат App API 1.20 (118 методов), включая типы и обёртки связи с телефоном. CLI работает на Python 3.10+ в Linux и Windows. Для новых методов `devices.companion.*` нужна SimplyOS 26.11-Dev.27. Основные функции Studio доступны с Release.26; новые API определяются версией ОС.

SDK не требует SimplyOS Studio. Распакуйте архив и запускайте:

```sh
python3 /путь/simplyos-sdk/simplyos-sdk.py init ./hello --template web --id org.example.hello --name Hello
python3 /путь/simplyos-sdk/simplyos-sdk.py init ./hello-python --template web-python --id org.example.python
python3 /путь/simplyos-sdk/simplyos-sdk.py validate ./hello
python3 /путь/simplyos-sdk/simplyos-sdk.py serve ./hello
python3 /путь/simplyos-sdk/simplyos-sdk.py pack ./hello
python3 /путь/simplyos-sdk/simplyos-sdk.py doctor
```

На Windows используйте `python` вместо `python3`. Если добавить папку SDK в `PYTHONPATH`, доступно также `python -m simplyos_sdk`. `serve` печатает адрес `http://127.0.0.1:ПОРТ/`; открывайте именно этот адрес. Остановка — Ctrl+C. Порт назначается автоматически, при необходимости задаётся `--port`. Входящие подключения из сети не принимаются.

## Веб-приложение

Шаблон содержит HTML, CSS, JavaScript, SVG-иконку, манифест, обёртку `simplyos.js`, типы `simplyos.d.ts` и задачи IDE. В JavaScript:

```js
import {request} from './simplyos.js';
const info = await request('system.api.info');
await request('notifications.post', {title: 'Готово', message: 'Операция завершена'});
```

Разрешения перечисляются в `manifest.json`; текущие методы и права находятся в `api-contract.json`. SDK проверяет имена прав, пути и структуру манифеста. Это не заменяет проверку безопасности магазином или ОС.

## Веб + Python

В манифесте указываются `pythonService: "backend/service.py"` и разрешение `services.python`. Контракт компонента:

```python
def handle(method: str, params: dict):
    if method == 'sum':
        return {'value': params['a'] + params['b']}
    raise ValueError('Неизвестный метод')
```

```js
import {service} from './simplyos.js';
const result = await service('sum', {a: 2, b: 3});
```

Компонент выполняется с правами текущего пользователя. Он не изолирован как веб-приложение: ему доступны пользовательские файлы и сеть. В установленной ОС требуется официальный пакет магазина, доверие, разрешение и отдельное согласие пользователя. Согласие привязано к содержимому компонента и теряет силу после его изменения; право можно отозвать в настройках. Локально установленный VPK не получает право выполнения Python, даже после назначения доверия. Такие пакеты передаются правообладателю магазина для проверки и публикации.

В ОС каждый вызов выполняется отдельным Python-процессом, время ограничено 30 секундами; вход и результат — JSON до 1 МБ. Состояние между вызовами храните в пользовательских файлах. Долгоживущие службы, автозапуск демона и операции root этим API не регистрируются. Для таких служб требуется отдельный проверенный системный адаптер; не включайте произвольные systemd-юниты и установочные скрипты в VPK.

Зависимости Python включайте в `backend/vendor` под нужную платформу и версию Python. Пакет не выполняет `pip install` на устройстве пользователя. Не включайте `.env`, пароли и ключи. Для работы с устройствами, уведомлениями и диалогами используйте системный API из веб-части, а не прямое обращение к внутреннему HTTP API оболочки.

## Локальная проверка и отладка

`serve` явно выполняет Python-код выбранного проекта. Запускайте только проекты, которым доверяете. Локальный адаптер поддерживает сведения об API, данные приложения в памяти, сообщения в журнале и Python-вызовы. Другие методы отвечают ошибкой о недоступной эмуляции. Данные не являются реальным профилем SimplyOS; уведомления не выдаются за системные. Статические ресурсы из `backend`, скрытые файлы и каталог `node_modules` недоступны через preview.

Для Python в Studio доступны точки останова и конфигурация `SimplyOS: Python service`. Запустите её через раздел отладки и откройте напечатанный адрес. При запросе к компоненту отладчик остановится на соответствующей строке. Обычные сообщения Python видны в терминале. Сообщения console.log/warn/error и необработанные ошибки веб-интерфейса передаются в терминал задачи IDE. Node.js можно отлаживать штатным JavaScript-отладчиком Code OSS. Подключение точек останова веб-интерфейса к гостевой вкладке встроенного браузера в этот выпуск не включено.

## Сборка

`pack` создаёт `dist/<id>-<версия>.vpk`, не запускает установщики и не подписывает пакет ключами магазина. Исключаются `.git`, `.venv`, `node_modules`, `dist`, `.vscode`, `.env*`, `.pem`, `.key`, `.pyc` и существующие VPK. Это страховка от распространённых ошибок, а не поиск всех секретов: содержимое архива проверяет разработчик. Связанный frontend предварительно собирается его собственным сборщиком. Необходимые ресурсы должны находиться внутри проекта; зависимости из `node_modules` предварительно объединяются сборщиком. Ограничение установщика — 2000 файлов.

## Другие языки

Studio использует Code OSS/code-server, предоставляет терминал, поиск, Git, задачи, расширения, языковые серверы и отладчики. Мастер содержит также Python, CMake/C++, Node.js, Cargo/Rust и Go. Python, Git, Node.js/npm, C/C++, make, CMake и GDB устанавливаются вместе со Studio через зеркало SimplyOS. Python-расширение и debugpy включены в VPK. Для Rust, Go, Java, .NET и других языков нужны соответствующие компиляторы и расширения; `doctor` показывает, что доступно. Поддержка языка расширением не означает наличия компилятора. Расширения Open VSX устанавливаются отдельно, с собственными лицензиями. Visual Studio Marketplace не используется.


## Установка Studio и расширения

Studio устанавливается из Магазина SimplyOS вместе с движком, SDK и Python-отладчиком. Рекомендуются 4 ГБ ОЗУ и не менее 3 ГБ свободного места с учётом инструментов и временных файлов установки. Обновите систему до 26.11-Dev.6, установите SimplyOS Studio и откройте его из меню приложений. Команды SDK находятся в палитре Ctrl+Shift+P: введите SimplyOS. Файлы и папки можно открыть через контекстное меню проводника и рабочего стола. Для запуска кода в незнакомой рабочей папке сначала подтвердите доверие через стандартный режим Workspace Trust; Studio не отключает эту проверку.

Для другой IDE распакуйте SDK. В Code OSS/совместимом редакторе можно установить комплектный `nontec.simplyos-sdk-0.3.0.vsix` командой «Install from VSIX», затем указать `simplyos.sdkPath` и `simplyos.python`. Сам SDK не зависит от VSIX. Другие редакторы могут вызывать CLI как внешние задачи. Создание и редактирование кода не требуют доступа к облаку; первоначальная установка из магазина и загрузка дополнительных инструментов требуют сети.


## Скачать SDK отдельно

[SDK 0.3.0](https://simplyos.ru/market/sdk/simplyos-sdk-0.3.0.zip) · [Расширение 0.3.0](https://simplyos.ru/market/sdk/nontec.simplyos-sdk-0.3.0.vsix) · [SHA-256](https://simplyos.ru/market/sdk/SDK-0.3.0-SHA256SUMS) · [Подпись](https://simplyos.ru/market/sdk/SDK-0.3.0-SHA256SUMS.sig)

```sh
openssl dgst -sha256 -verify update-signing-public.pem -signature SDK-0.3.0-SHA256SUMS.sig SDK-0.3.0-SHA256SUMS
sha256sum -c SDK-0.3.0-SHA256SUMS
```

Список сумм охватывает ZIP и VSIX версии 0.3.0. Проверяйте соответствующее имя файла. [Открытый ключ](update-signing-public.pem) проверяет подписи и не позволяет подписывать пакеты. Резервный сервер: `https://updatesios.nontec.ru/store/sdk/`.

## Совместимость SDK и API

SDK, VSIX и Studio выпускаются как 0.3.0. В SDK и Studio вложен идентичный контракт API 1.20 с 118 методами, полные типы мультимедиа, транспорта и подключённых устройств. `release.json` указывает версии и число методов; `doctor` выводит версии SDK и API. Новые проекты получают `companions.js` и `companions.d.ts`.

Версия SDK не добавляет реализацию API в установленную ОС. Release.26 предоставляет API 1.19; для связи с телефоном обновитесь до Dev.27 или последующего выпуска с API 1.20. Проверяйте доступность методов через `system.api.info`. Предварительный просмотр SDK возвращает недоступность реального телефона вместо имитации успешной операции. Старый SDK 0.2.1 остаётся архивным выпуском с API 1.16.
