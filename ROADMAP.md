# Текущее состояние и цель

SimplyOS — операционная система для компьютеров x86-64. Текущая архитектура использует ядро Linux и пакетную базу Debian. Пользовательский интерфейс, системные приложения, API приложений, установщик и механизм обновлений развиваются как компоненты SimplyOS.

Цель проекта — система для повседневной работы, которую можно установить на компьютер, использовать для работы с файлами и документами, доступа в интернет и подключения устройств, а также обновлять через инфраструктуру SimplyOS. В дальнейшем планируется развивать собственные компоненты и постепенно снижать зависимость от пакетной базы Debian там, где это практически оправдано.

## 1. Установка и первый запуск

**Цель:** подготовить установочный образ, после установки которого пользователь получает работающую графическую систему.

- **Сделано:** установочный ISO и установщик, создание пользователя, запуск рабочего стола и экран знакомства с системой.
- **В работе:** проверка установки и первого запуска на более широком наборе компьютеров.

SimplyOS устанавливается и запускается на проверенных физических и виртуальных машинах. Совместимость с новым оборудованием проверяется отдельно.

## 2. Рабочий стол и основные функции

**Цель:** обеспечить повседневную работу без обязательного использования терминала.

- **Сделано:** окна приложений, панель задач, рабочий стол, меню приложений, файловый менеджер, настройки, уведомления и работа со съёмными накопителями.
- **Сделано:** блокировка экрана, сон, горячие клавиши, снимки экрана и резервное копирование.
- **Сделано в ветке Dev:** выделение и перемещение групп значков на рабочем столе.
- **Сделано в ветке Dev:** несколько независимых окон браузера, файлового менеджера и редакторов с отдельными кнопками на панели задач.
- **В работе:** проверка поведения окон и интерфейса на разных разрешениях экрана.

Основные действия доступны через графический интерфейс. Отдельные сценарии дорабатываются по результатам использования.

## 3. Обновления и распространение приложений

**Цель:** доставлять исправления и программы через управляемые каналы SimplyOS.

- **Сделано:** каналы Release и Dev, Центр обновлений, подписанный каталог пакетов и зеркало системных пакетов.
- **Сделано:** Магазин приложений, проверка требований приложения к версии ОС, установка и обновление через Магазин.
- **В работе:** проверка переходов между версиями и восстановления после прерванного обновления.

Обновления ОС и приложения распространяются через сервер SimplyOS. Новые возможности сначала могут проверяться в Dev, затем включаться в Release.

## 4. Приложения и системный API

**Цель:** предоставить приложениям единый способ работы с функциями ОС и управление разрешениями.

- **Сделано:** API для файлов, уведомлений, сети, буфера обмена, оборудования и печати.
- **Сделано:** просмотр и отзыв разрешений приложений в настройках.
- **Сделано:** в Магазине доступны Collabora Office, SimplyVPN, SimplyOS Benchmark, «Mesh Радио» и другие приложения.
- **В работе:** расширение API с сохранением совместимости установленных приложений.

Приложения работают локально и используют системные возможности через определённые интерфейсы. Совместимость API проверяется при добавлении новых функций.

## 5. Сеть и оборудование

**Цель:** обеспечить работу SimplyOS на разных компьютерах и с распространёнными внешними устройствами.

- **Реализовано:** управление Wi-Fi, Ethernet, Bluetooth, звуком, экраном и принтерами; поддержка Fn-клавиш, нескольких экранов и системной печати.
- **Сделано:** прошивки и драйверы для части оборудования добавлены в установщик и зеркало.
- **В работе:** расширение перечня совместимых устройств, проверка сна, пробуждения и переподключения сети.

Работа конкретного адаптера или принтера зависит от оборудования и требует проверки.

## 6. Встроенный браузер

**Цель:** открывать современные сайты внутри интерфейса SimplyOS.

- **Сделано:** вкладки, адресная строка, история, загрузки и контекстные действия.
- **Сделано в ветке Dev:** страницы отображаются напрямую во встроенных вкладках Chromium с исходным HTTPS-адресом. Добавлены скачивание и отправка файлов через системные средства SimplyOS.
- **В работе:** проверка входа на сайты, WebSocket, буфера обмена и мультимедиа в сложных веб-приложениях на установленной системе.

Браузер пригоден для части повседневных задач. Совместимость со сложными веб-приложениями остаётся одним из направлений разработки.

## 7. Надёжность выпусков

**Цель:** выпускать обновления и установочные образы с проверяемым результатом.

- **Сделано:** пакеты обновлений подписываются; история изменений публикуется отдельно.
- **Постоянная задача:** перед новым Release проверять установку, обновление, основные приложения и оборудование.
- **Следующий этап:** расширить повторяемые автоматические проверки и набор тестовых компьютеров.
