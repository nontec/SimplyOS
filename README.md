# SimplyOS

SimplyOS Vole — операционная система для персональных компьютеров x86-64 на ядре Linux и пакетной базе Debian GNU/Linux 13. Рабочий стол, системные приложения, установщик, системный API и механизм обновлений развиваются как компоненты SimplyOS. Vole — кодовое имя выпуска.

Интерфейс создан на веб-технологиях и работает в Electron под Wayland/labwc. Системные функции предоставляет локальный Python-backend; административные действия выполняет отдельный посредник с PAM-подтверждением. Страницы встроенного браузера отображаются непосредственно движком Chromium внутри окна SimplyOS.

[Официальный сайт](https://simplyos.ru/) · [Скачать ISO](https://simplyos.ru/#download) · [История изменений](CHANGELOG.md) · [Дорожная карта](ROADMAP.md)

## Состояние выпуска

По состоянию на 9 ноября 2026 года опубликованы 26.11-Release.26 и 26.11-Dev.27. Актуальный установочный ISO — 26.11-Release.16. Номер ISO и номер последнего обновления различаются: после установки откройте Центр обновлений. В системный пакет Release.26 включён App API 1.19.

Release — основной канал. Dev предназначен для проверки изменений и может работать нестабильно; переход в него требует предупреждения и подтверждения администратора. Обновления ОС накопительные, приложения из Магазина обновляются отдельно.

## Возможности

- Рабочий стол с окнами, панелью задач, меню приложений, быстрыми настройками и центром уведомлений; несколько окон поддерживающих это приложений.
- Проводник со съёмными и сетевыми накопителями, работой с архивами и файловыми ассоциациями.
- Встроенный браузер, почта, камера, просмотр PDF, изображений, музыки и видео, редакторы, калькулятор, часы с фоновыми будильниками, терминал и системные утилиты.
- Настройки сети, устройств, печати, нескольких экранов, электропитания, персонализации и экранной клавиатуры. Возможности зависят от драйверов.
- Резервные копии, автоматические точки, откат системной среды из GRUB и приложение «Диагностика». Откат среды не возвращает версии ядра/APT и не заменяет полную копию данных.
- Переносимые рабочие пространства с окнами, вкладками и поддерживаемыми документами в зашифрованном файле.
- Магазин с Collabora Office, SimplyVPN, PeerRing, веб-клиентами общения, «Mesh Радио», SimplyOS Studio, торрент-клиентом, удалённым рабочим столом и другими программами.

## Установка

Для сетевого ISO нужны интернет и доступ к инфраструктуре SimplyOS. Рекомендуются от 4 ГиБ ОЗУ и от 32 ГиБ дискового пространства. Поддерживаются UEFI и BIOS; совместная установка на GPT-диск и Secure Boot предусмотрены для UEFI при выполнении условий инструкции. Для VirtualBox не требуется специально включать 3D-ускорение.

[Скачать ISO](https://simplyos.ru/#download) · [Инструкция и ограничения](docs/INSTALLATION.md) · [Проверка SHA-256 и подписи](docs/VERIFY-ISO.md) · [Руководство пользователя](docs/USER-GUIDE.md)

Перед изменением разметки сохраните резервную копию важных файлов. Работа конкретного оборудования и сайтов требует проверки; поддержка Secure Boot не означает автоматическую совместимость сторонних DKMS-модулей.

## О репозитории

Здесь публикуются документация, история обновлений и дорожная карта. Полный исходный код собственных компонентов ОС в этом репозитории не размещён. Отдельно доступны [исходники «Mesh Радио» под GPLv3](apps/mesh-radio); условия находятся в папке приложения.

Использование SimplyOS в личных домашних целях бесплатно.

SimplyOS Connect 1.0.0 доступен в Магазине для Dev.27 и последующих систем с API 1.20: связь с Android через KDE Connect в локальной сети, передача данных, заряд, поиск телефона, уведомления и SMS с разрешениями пользователя. [Подключение и ограничения](docs/SIMPLYOS-CONNECT.md). Трансляция экрана и разговоры через компьютер остаются в планах.
