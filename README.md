# SimplyOS

SimplyOS — операционная система для персональных компьютеров с архитектурой x86-64. Текущая версия использует ядро Linux и пакетную базу Debian GNU/Linux. Рабочий стол, системные приложения, интерфейс для приложений, установщик и механизм обновлений развиваются как компоненты SimplyOS.

Система предназначена для повседневной работы: доступа в интернет, работы с файлами и документами, подключения устройств и установки приложений через Магазин SimplyOS.

## Установка и обновления

Установочный образ и сведения о SimplyOS доступны на [официальном сайте](https://nontec.ru/). Для установки через текущий образ требуется подключение к интернету. После установки обновления ОС доступны через Центр обновлений: канал Release содержит основные выпуски, канал Dev предназначен для предварительной проверки изменений.

Актуальный установочный образ: [26.10-Release.98, x86-64](https://updatesios.nontec.ru/iso/SimplyOS-26.10-Release.98-amd64.iso). Поддерживаются UEFI и BIOS; в виртуальных машинах включать 3D-ускорение не требуется. [Контрольная сумма](https://updatesios.nontec.ru/iso/SimplyOS-26.10-Release.98-amd64.iso.sha256) и [подпись](https://updatesios.nontec.ru/iso/SimplyOS-26.10-Release.98-amd64.iso.sha256.sig).
