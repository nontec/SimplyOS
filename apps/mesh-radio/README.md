# Mesh Радио 2.0.1

Приложение SimplyOS для Meshtastic и MeshCore: USB/COM, Bluetooth LE и TCP через сеть. Поддерживаются список узлов, отправка и получение текстовых сообщений, история и изменение имени и основных радиопараметров, доступных в интерфейсе. Требуется SimplyOS 26.11-Dev.6, App API 1.15.

Протоколы реализованы в приложении. Вызовы `radio.*` в `app.js` — внутренние методы этого приложения; они не являются системным API. Через `window.simplyos.request` используются только универсальные средства ввода-вывода и обычные API данных, уведомлений и открытия ссылок. Системные `mesh.*` не используются. Python-компонент для этой версии не нужен.

## Сборка

Требуются Node.js 20 или новее, npm и Python 3.10 или новее:

```sh
cd source
npm ci --ignore-scripts
node build.mjs
cd ..
python3 pack.py
```

Результат — `dist/mesh-radio-2.0.1.vpk`. В пакет включаются собранный браузерный модуль, интерфейс, манифест, иконки и лицензии; сборочные инструменты не устанавливаются на устройство пользователя. Для установки личной сборки выберите другой ID в манифесте либо удалите установленную версию с таким ID. Доверие и разрешения выдаёт SimplyOS, а не код приложения.

`source/vendor/meshtastic-js` содержит исходники GPL-библиотеки Meshtastic, зафиксированные по коммиту из `source/vendor/UPSTREAM.json`. Обработчик ошибок потока изменён: разрыв или ошибка декодирования переводит устройство в отключённое состояние, а не оставляет необработанный Promise. `source/vendor/protobufs` содержит исходные TS-модули Meshtastic Protobufs 2.7.0 из опубликованного пакета. `source/vendor/meshcore` содержит JS-исходники MeshCore 1.15.0. Данные npm-зависимостей и их контрольные суммы записаны в `source/package-lock.json`; оригинальные архивы зависимостей находятся в `source/vendor/npm-sources`. Предпочтительные исходники зависимостей с точными коммитами также включены в `source/vendor/upstream-dependencies`. Неизменённые npm и esbuild являются отдельными инструментами сборки.

## Устройство приложения

- `app.js` — интерфейс, история, уведомления.
- `source/radio.js` — протокольные адаптеры Meshtastic и MeshCore.
- `source/build.mjs` — сборка автономного `radio.js` без обращения к CDN.
- `manifest.json` — минимальные разрешения SimplyOS и ссылка на исходники.

ОС запрашивает подтверждение доступа к конкретному порту, устройству или сетевому адресу. Bluetooth-устройства, требующие PIN, предварительно сопрягаются в настройках SimplyOS. При изменении настройки LoRa приложение использует прочитанную конфигурацию и сохраняет остальные поля; если исходная конфигурация ещё не получена, запись отменяется. Изменение параметров устройства не выполняется автоматически при запуске приложения.

Программные тесты проверяют фрейминг, сообщения и сохранение настроек на имитаторах обоих протоколов. Совместимость конкретной прошивки и оборудования проверяется отдельно.
