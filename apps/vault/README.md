# Менеджер паролей SimplyOS

Приложение 1.0.1 для SimplyOS 26.11-Dev.32 и новее. Открывает и создаёт локальные базы KDBX, добавляет записи и копирует данные для входа через системный буфер. Движок KeePassXC устанавливается из зеркала пакетов SimplyOS.

- `app/` — исходники VPK из Магазина.
- `system/vault.py` — обработчик KDBX в системном бэкенде.
- `system/vault-bridge.ts` — часть моста API, обслуживающая менеджер паролей.
- `system/password-dialog.ts` — системное окно ввода пароля.
- `system/vault-clipboard.cjs` — обработчик копирования и очистки буфера обмена.

Системные файлы приведены для проверки реализации в Dev.32. Для их работы нужны службы и оболочка SimplyOS. Приложение получает названия и идентификаторы записей. Мастер-пароль передаётся из системного окна локальному бэкенду, который запускает KeePassXC CLI с паролем на стандартном вводе. Логин или пароль выбранной записи передаётся в системный буфер обмена. Через 30 секунд система очищает буфер, если скопированное значение всё ещё находится в нём. Хранилище блокируется при выходе из сеанса, блокировке экрана, закрытии окна или после трёх минут бездействия.

## Сборка VPK

Выполните команду из этой папки с [SDK SimplyOS](https://simplyos.ru/market/sdk/), поддерживающим App API 1.21.

```sh
python3 /path/to/sdk/simplyos-sdk.py pack app --output simplyos-vault-1.0.1.vpk
```

Системный доступ к KDBX проверяет разрешение `vault.local` и происхождение пакета из подписанного Магазина SimplyOS.
