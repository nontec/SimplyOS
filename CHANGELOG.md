# История изменений SimplyOS

Здесь перечислены опубликованные обновления SimplyOS, начиная с 26.10-Release.20. Записи составлены по заметкам выпущенных пакетов. `Release` — основной канал, `Dev` — канал предварительной проверки. Обновления накопительные: следующий пакет включает изменения предыдущих выпусков. В `Release` входят проверенные изменения, которые ранее могли появиться в `Dev`.

Версии приведены в порядке публикации, от новых к старым. Номер версии не следует понимать как дату публикации.

## 26.10-Dev.68

- Исправлена проверка результата системной службы при создании пользователя и смене пароля на Debian 13.
- Включены изменения Dev.67: отдельные пользовательские файлы, приложения из Магазина и профили браузера, переключение учётных записей и отключение переименования пользователя.

## 26.10-Dev.67

- Исправлены создание учётных записей и смена пароля Linux через системную службу.
- Вход под другой учётной записью переключает backend SimplyOS и профиль Chromium. Пользовательские файлы, настройки браузера и приложения из Магазина хранятся отдельно для каждого пользователя.
- Временная функция переименования пользователя убрана из настроек и системного API.

## 26.10-Dev.66

- Ход обновления пакетов Linux восстанавливается при повторном открытии настроек и после перезагрузки интерфейса. Выпуск включает исправления Dev.65.

## 26.10-Dev.65

- Обновление системных пакетов Linux в настройках запускается как отдельное задание: установка продолжается независимо от ожидания страницы.
- В Центре обновлений и уведомлениях показываются этапы работы APT, а при установке — доступный процент выполнения. Ошибка сопровождается причиной из APT.
- После успешного поиска список обновляемых пакетов обновляется автоматически. Действие по-прежнему требует подтверждения паролем администратора Linux.

## 26.10-Release.64

- Браузер улучшен для современных сайтов внутри окна SimplyOS. Добавлены проверки сетевых адресов при загрузке и перенаправлениях, а данные сайтов разделены между сеансами. Обмен с Chromium переведён с отладочного TCP-порта на закрытый канал.
- Добавлена многооконность для браузера, Файлов, редакторов, терминала и Collabora Office. Улучшено переключение через панель задач, групповое выделение значков рабочего стола и контекстное меню.
- Для приложений усилена привязка системного API к сеансу окна. Добавлена управляемая фоновая работа: состояние VPN видно в центре уведомлений после закрытия его окна.
- Файловые операции ограничены разрешёнными пользовательскими каталогами и подключёнными накопителями. Погодный API требует входа в систему. Исправлена работа HTTPS на Python 3.13 и обновлена библиотека `libbrotli1`.
- Новый установочный ISO шифрует системный раздел с помощью LUKS2. Контрольная сумма образа подписана отдельным ключом. Шифрование существующих установок требует резервной копии и переустановки.

## 26.10-Dev.63

- Для нового установочного образа пароль шифрования диска ограничен символами, доступными при ранней загрузке, и проверяется до очистки диска.
- Выпуск содержит исправления безопасности Dev.62.

## 26.10-Dev.62

- Встроенный браузер передаёт команды Chromium через закрытый канал вместо локального отладочного TCP-порта.
- В обновление включена исправленная версия `libbrotli1` из зеркала SimplyOS; пакет устанавливается вместе с обновлением.
- Исправлена работа HTTPS в браузерном прокси на Python 3.13.
- Погодный API теперь требует входа в SimplyOS.
- Для будущего установочного образа подготовлено шифрование системного раздела LUKS2 с отдельным паролем диска.

## 26.10-Dev.61

- Встроенный браузер закрепляет проверенный сетевой адрес при загрузке страниц, файлов и WebSocket-подключениях. Повторная проверка выполняется после перенаправления.
- Файловые операции ограничены домашней папкой пользователя и подключёнными внешними накопителями.
- Данные сайтов во встроенном браузере разделены между сеансами входа.
- Для обновлений зафиксирован набор Python-компонентов: при сборке и установке проверяются имена, размеры и контрольные суммы файлов.

## 26.10-Dev.60

- Добавлен реестр фоновых служб приложений. Состояние VPN видно в центре уведомлений и быстрых настройках после закрытия окна SimplyVPN.
- Из центра уведомлений можно открыть SimplyVPN или отключить соединение после ввода пароля Linux. Карточка активной службы сохраняется при очистке обычных уведомлений.
- App API 1.9 добавляет `background.status` и `background.stop` для собственной зарегистрированной службы. Регистрация фонового процесса ограничена проверенными пакетами Магазина и поддерживаемыми системными адаптерами.
- В Магазине опубликован SimplyVPN 1.3.5 с поддержкой нового API; пакет требует Dev.60 или более новую версию ОС.

## 26.10-Dev.59

- Системный API приложений привязан к отдельному сеансу окна. После навигации внутри iframe прежний сеанс прекращается.
- Ответы API и системного выбора файлов передаются исходному документу через отдельный канал, чтобы следующий документ в том же окне не получил их.
- Обновлено описание применения разрешений и различий между приложениями из Магазина и локальными VPK.

## 26.10-Dev.58

- Исправлено переключение нескольких окон через панель задач: нажатие выводит окно вперёд, если оно находится позади другого. Повторное нажатие на кнопку активного окна сворачивает его.
- Обновление включает все изменения многооконности из Dev.57.

## 26.10-Dev.57

- Добавлено несколько независимых окон браузера, Файлов, текстового редактора, Рисовалки, просмотра PDF, терминала и редакторов Collabora Office.
- Каждое окно получает собственную кнопку на панели задач; доступны переключение, сворачивание и закрытие отдельного окна.
- Команда «Новое окно» добавлена в браузер, Файлы, текстовый редактор и меню кнопки приложения на панели задач. Для браузера и Файлов работает Ctrl+N, для текстового редактора — Ctrl+Shift+N.
- Файлы документов и PDF открываются в новых окнах. Вкладки браузера сохраняются отдельно для каждого окна, расположение нескольких окон восстанавливается после перезагрузки интерфейса.

## 26.10-Dev.56

- Добавлен режим совместимости для современных сайтов внутри окна браузера SimplyOS: страницы открываются на исходном HTTPS-адресе без отдельного окна Chromium.
- Рабочий стол поддерживает выделение нескольких значков рамкой, совместное перемещение и групповое удаление файлов.
- В меню «Создать» появляются файлы DOCX, XLSX и PPTX при наличии соответствующих приложений Collabora Office.
- Нажатие на содержимое веб-страницы теперь выводит окно браузера на передний план. Системные значки больше не перетаскиваются как изображения.
- Контекстные меню браузера и рабочего стола используют общий механизм; меню создания учитывает установленный набор приложений.

## 26.10-Dev.55

- Исправлена загрузка ресурсов с внешних доменов во встроенном браузере; обновлены обработка CORS, cookies и User-Agent.
- Для сайтов, которым нужен исходный HTTPS-адрес, было добавлено открытие в отдельном Chromium. В Dev.56 этот способ заменён встроенным режимом.

## 26.10-Release.54

- Ограничено время ожидания при Bluetooth-подключении в приложении «Mesh Радио». При сбое приложение сообщает причину вместо бесконечного ожидания.

## 26.10-Release.53

- Добавлено приложение «Mesh Радио» для Meshtastic и MeshCore с подключением по USB/COM, Bluetooth и локальному IP, обменом сообщениями и настройкой основных параметров.
- Системный API обновлён до версии 1.8 для работы с радиоустройствами и разрешениями приложений.
- Улучшено определение модели графического адаптера; в зеркало добавлены средства диагностики Ethernet.

## 26.10-Dev.52

- Исправлено отображение модели графического адаптера в бенчмарке и системном API. При отсутствии `lspci` используется локальный каталог PCI ID.
- Для новых установок подготовлен пакет `ethtool`.

## 26.10-Release.51

- Добавлен системный API с моделью процессора, графического адаптера и объёмом оперативной памяти без идентификаторов устройства.
- SimplyOS Benchmark использует эти данные для подробных результатов, публикуемых только после согласия пользователя.

## 26.10-Release.50

- Исправлено переключение окон при нажатии на содержимое встроенных приложений.

## 26.10-Release.49

- Исправлены значки кнопок управления окнами: размещение слева и справа, сворачивание, разворачивание и закрытие.

## 26.10-Release.48

- Возвращены индивидуальные значки приложений в меню, на рабочем столе и панели задач. Иконки Material Design сохранены внутри окон.
- Обновлены значки Калькулятора, SimplyOS Benchmark и игры «Плитки 2048».

## 26.10-Release.47

- В стандартный набор добавлен Калькулятор; исправлены значки и график температуры в Диспетчере задач.
- В Магазине появились SimplyOS Benchmark и автономная игра «Плитки 2048».
- Включены проверенные изменения предыдущих сборок Dev, в том числе сохранение учётной записи Почты после перезагрузки.

## 26.10-Release.39 и 26.10-Release.38

- Ранние релизные пакеты с Калькулятором, SimplyOS Benchmark, игрой «Плитки 2048» и исправлениями Диспетчера задач. Позднее выпущен обновлённый пакет Release.47.

## 26.10-Dev.46

- Почта сохраняет учётную запись между перезагрузками и удаляет учётные данные при очистке данных приложения.
- Обновлена работа встроенных приложений с системным API и проверка состояния VPN при свёрнутом окне.

## 26.10-Dev.45

- Исправлено создание снимков экрана по Print Screen и Win+Shift+S в сеансе Wayland. Файлы сохраняются в папке «Изображения».

## 26.10-Dev.44

- Добавлены API уведомлений, ограниченных сетевых запросов, камеры и микрофона, а также просмотра устройств Bluetooth и USB для доверенных приложений.

## 26.10-Dev.43

- Улучшена диагностика создания снимков экрана и добавлена обработка Print Screen.
- Новые файлы Writer, Calc и Impress создаются как временные черновики; пустые черновики удаляются при закрытии.

## 26.10-Dev.42

- Исправлено повторное подключение к сохранённым сетям Wi-Fi через профили NetworkManager.

## 26.10-Dev.41

- Перед установкой CUPS и драйверов печати обновляется список пакетов зеркала SimplyOS; ошибки доступности показываются в настройках.

## 26.10-Dev.40

- Ctrl+P открывает системное окно печати с выбором принтера, числа копий, двусторонней печати и страниц PDF.
- Collabora Writer, Calc и Impress передают подготовленный PDF в SimplyOS для печати.

## 26.10-Dev.39

- Улучшены определение и установка службы печати: учитывается язык системы, показывается ход установки и причина ошибки.

## 26.10-Dev.38

- При первом входе после установки появляется краткое знакомство с системой.
- В настройках добавлены обнаружение принтеров, добавление и удаление устройств, выбор принтера по умолчанию и управление очередью. Опубликован API печати для приложений.

## 26.10-Release.37

- Исправлены операции установки и обновления, которые могли завершаться ошибкой «файловая система только для чтения».
- SimplyVPN сохраняет конфигурацию в предназначенном каталоге; добавлены проверка доступности сервера и показ задержки.

## 26.10-Release.36

- В SimplyVPN добавлено контекстное меню для работы с текстом.
- Доверенным приложениям доступен текстовый буфер обмена через отдельные отзывные разрешения.

## 26.10-Release.35

- В SimplyVPN добавлены загрузка и обновление HTTPS-подписок в форматах списков ссылок, Base64, Clash YAML и sing-box JSON.
- Добавлены отображение процесса загрузки и сообщения об ошибках подписки.

## 26.10-Release.34

- Исправлена установка SimplyVPN при ограничениях записи системного посредника. Установка системных компонентов выполняется отдельным заданием.

## 26.10-Release.33

- Магазин начал показывать отдельные приложения наряду с наборами.
- Подготовлены системные операции SimplyVPN и App API 1.1 с подтверждением действий пользователем.

## 26.10-Release.32

- Исправлена компоновка окна подтверждения установки и обновления приложений: информация и поле пароля размещаются вертикально.

## 26.10-Release.31

- Офисный набор переименован в Collabora Office; редакторы — в Collabora Writer, Calc и Impress.
- При запуске из меню открывается новый файл, а при открытии из проводника — выбранный документ. Команды создания, открытия и сохранения находятся в интерфейсе Collabora.
- Исправлены поле пароля в установщике приложений и отображение состояния задания в Центре обновлений.

## 26.10-Release.30

- Презентации переведены на локальный офисный движок с поддержкой PPTX, ODP и PPT. Доступны инструменты для изображений, фигур, таблиц, диаграмм и заметок.
- Таблицы также переведены на локальный офисный движок.

## 26.10-Release.29

- «Документы» используют локальный движок Collabora Online для DOCX, ODT, DOC и RTF.
- Магазин показывает минимальную версию SimplyOS для приложения и объясняет, какое обновление требуется при несовместимости.

## 26.10-Dev.28

- Индикатор доступа к камере, микрофону и местоположению размещён у правого края кнопки Центра уведомлений без сдвига соседних элементов.

## 26.10-Dev.27

- Кнопка сворачивания всех окон возвращена справа от Центра уведомлений. Индикатор использования устройств перенесён внутрь кнопки Центра уведомлений.

## 26.10-Dev.26

- Добавлены повторное разворачивание окон после команды «Свернуть все», обновлённый Центр уведомлений и индикатор использования камеры, микрофона и местоположения.

## 26.10-Dev.25

- Разрешения приложений расположены вертикально; офисные документы можно открывать со съёмных накопителей.
- Подключение и отключение накопителя сопровождаются уведомлением, а при подключении показывается значок USB.

## 26.10-Dev.24

- Исправлено применение обновлений на системе Release.20. Включены сведения и разрешения приложений, обновлённая индикация загрузки и диагностика Wi-Fi.

## 26.10-Dev.23

- В настройках приложений появились сведения о разработчике, версии и разрешениях с возможностью отзыва.
- Обновлена индикация обычной загрузки и установки обновления; улучшена диагностика поиска Wi-Fi.

## 26.10-Dev.22

- Представлен SimplyOS App API 1.0 с единым перечнем методов и разрешений для VPK-приложений.
- Метод `files.open` передаёт приложению только выбранный пользователем файл; ошибки API возвращают код и понятное сообщение.

## 26.10-Dev.21

- Офисные форматы DOCX/ODT, XLSX/ODS и PPTX/ODP связаны с соответствующими приложениями.
- Добавлены экранная индикация громкости и настройки яркости.

## 26.10-Release.20

- Релиз включает проверенные изменения ветки Dev до Dev.19: таймауты блокировки и сна, резервные копии системы и пользовательских файлов, обработку клавиш Fn.
- В установочный образ добавлены прошивки для графических, звуковых и сетевых устройств.

Ранее выпускались обновления 0.4.x и 26.10 до Release.20. Их первоначальные заметки сохраняются в каталоге обновлений SimplyOS; этот файл начинается с Release.20.
