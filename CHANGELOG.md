# История изменений SimplyOS

Здесь перечислены опубликованные обновления SimplyOS, начиная с 26.10-Release.20. Записи составлены по заметкам выпущенных пакетов. `Release` — основной канал, `Dev` — канал предварительной проверки. Обновления накопительные: следующий пакет включает изменения предыдущих выпусков. В `Release` входят проверенные изменения, которые ранее могли появиться в `Dev`.

Версии приведены в порядке публикации, от новых к старым. Номер версии не следует понимать как дату публикации.

## 26.11-Dev.6

- Добавлены универсальные API для COM-портов, Bluetooth LE GATT, USB vendor-specific интерфейсов, TCP, UDP и WebSocket. Доступ выдаётся к выбранному устройству или адресу с подтверждением пользователя и проверкой разрешений.
- Расширены параметры COM-портов, работа с Bluetooth-характеристиками и подписками, получение состояния каналов и сведений о локальной сети. Добавлены ограничения доступа к служебным адресам и контроль сетевых узлов из манифеста.
- Mesh Радио 2.0 переведено на универсальные каналы. Протоколы Meshtastic и MeshCore поставляются внутри приложения, отдельный системный протокольный компонент не требуется. Исходники приложения, лицензии и инструкция сборки доступны публично.
- В Магазине добавлены сведения о лицензии и ссылки на исходный код, если их предоставляет разработчик.
- SDK и SimplyOS Studio обновлены до 0.2.0: добавлены обёртки транспорта, TypeScript-типы и актуальный контракт App API 1.15. Обновлена документация для разработчиков.

## 26.11-Dev.5

- Добавлена системная поддержка SimplyOS Studio — локальной IDE на Code OSS/code-server с отдельным профилем встроенного Chromium. Studio 0.1.0 распространяется через Магазин вместе с SDK и Python-отладчиком.
- В проводнике и на рабочем столе добавлено «Открыть в SimplyOS Studio» для файлов и папок. Поддерживаются несколько окон IDE.
- SDK содержит шаблоны web и web + Python, CLI проверки, локального запуска, сборки VPK и проверки инструментов; JS-обёртку, TypeScript-типы API и расширение IDE. Сообщения и ошибки веб-preview видны в терминале.
- В IDE добавлены шаблоны Python, CMake/C++, Node.js, Cargo/Rust и Go. Базовые инструменты устанавливаются из зеркала SimplyOS; дополнительные компиляторы подключаются отдельно.
- App API 1.14 добавляет `services.call` для Python-компонентов официальных приложений с отдельным согласием на выполнение кода с правами пользователя. Согласие связано с содержимым компонента; отзыв разрешения запрещает новые вызовы. Локальный VPK не получает это право автоматически.
- `studio.open` и `development.tools` закреплены за официальным SimplyOS Studio. Обновлена документация для разработчиков и опубликован отдельный SDK.

## 26.11-Dev.4

- Исправлено окно сведений о приложении: разрешения и автозапуск располагаются вертикально, длинные подписи переносятся, флажки сохраняют правильный размер.
- Исправлено отображение компактного логотипа SimplyOS в разделе «Система».

## 26.11-Dev.3

- В разделе «Система» добавлены логотип SimplyOS и кодовое имя Vole.
- В сведениях о поддерживаемых приложениях добавлен переключатель автозапуска. Для «Торрентов» он управляет запуском личной службы при включении устройства; обновление компонентов сохраняет настройку.
- App API 1.13 добавляет `autostart.get` и `autostart.set`, разрешение `autostart.manage` и поле манифеста `supportsAutostart`. Настройки разделены между пользователями, программное изменение требует подтверждения.
- Исправлен доступ локального офисного редактора к системному буферу обмена для копирования обычного и форматированного текста и вставки обратно.
- В Telegram и отдельных веб-клиентах добавлен системный выбор папки и имени скачиваемого файла. Отмена прекращает загрузку; существующие файлы не перезаписываются, возвращается фактическое имя сохранённого файла.
- Добавлено русскоязычное контекстное меню редактирования текста. Недоступные действия отключаются; меню документов Collabora сохранено.

## 26.11-Dev.2

- Исправлены размер и начертание текста заголовка быстрых настроек и кнопки разворачивания. Общее правило оформления заголовков больше не увеличивает текст кнопки.
- Исправлено направление стрелок: «Развернуть» — вверх, «Свернуть» — вниз.
- Компактный вид с четырьмя плитками сохранён. Уведомления и блок «Обзор» не изменены.

## 26.11-Dev.1

- В быстрых настройках добавлены компактный вид с четырьмя доступными плитками и разворачивание остальных. Уведомления и «Обзор» сохраняют прежнее поведение.
- Исправлены прогресс и завершение загрузки в браузере. Сетевое скачивание и сохранение в папку пользователя связаны одной записью, показываются фактические имя и размер, включая переименование при совпадении имён.
- Исправлены зависшие записи и обработка прерывания загрузки; состояние сверяется с локальной службой.
- Переработаны панели загрузок, настроек, меню, истории и закладок браузера. Исправлено скрытие закрытой панели, улучшена работа в узком окне.
- В конфигурации Collabora отключён автоматический показ приветствия. Настройка применяется и к уже установленному движку при обновлении ОС.
- Исправлено закрытие неизменённых документов Writer, Calc и Impress в режиме просмотра: лишний запрос сохранения больше не блокирует закрытие.
- Сохраняется проверка записи реальных изменений. Ошибка сохранения или новые правки во время записи блокируют закрытие.
- Объединены одновременные запросы сохранения и закрытия одного документа.
- Ресурсы офисного интерфейса получают адреса с контрольной суммой; после обновления не используется старый обработчик из кэша.
- Начата ноябрьская нумерация с итерации 1. Проверено сравнение с октябрьскими версиями.

## 26.10-Dev.100

- В настройках «Время и язык» появился выбор Alt+Shift, Ctrl+Shift или Win+Пробел для смены раскладки. Сочетание сохраняется для пользователя.
- Горячие клавиши стандартных приложений работают по физическим клавишам независимо от раскладки. Системные сочетания передаются оболочке из встроенного браузера.
- Alt+F4 закрывает активное окно с обычной проверкой несохранённых данных. Win+Shift+стрелка вниз сворачивает активное окно. Добавлена памятка сочетаний в настройках.
- В разделе «Экран» можно выбрать открытие новых окон обычными или развёрнутыми. Параметр сохраняется, не меняя расположение восстанавливаемых рабочих пространств.
- Фиолетовый цвет индикатора в Центре уведомлений обозначает входящее подключение к удалённому рабочему столу. Учитываются подключённые клиенты, а не только включённая служба.
- Всплывающие уведомления приложений плавно появляются и исчезают через 3 секунды; карточки остаются в Центре уведомлений.
- Актуализирована документация API: состояние удалённых клиентов и рекомендации по обработке клавиш.

## 26.10-Dev.99

- Переход в Dev сопровождается предупреждением о нестабильности. Смена ветки требует повторного ввода пароля администратора; проверка выполняется системной службой.
- При смене ветки отменяется подготовленное обновление другой ветки. Установленная версия автоматически не откатывается.
- Уведомления приложений получили отдельные всплывающие карточки с иконкой, названием и временем и остаются в Центре уведомлений. По нажатию открывается окно приложения.
- Краткие системные подтверждения, например создание скриншота, показываются временно и не попадают в Центр уведомлений.
- Уточнена документация `notifications.post`: приложения не могут выдавать свои уведомления за системные. Новых разрешений не требуется.

## 26.10-Release.98

Выпуск включает изменения Dev.76–Dev.97 и обновлённый установщик. Изменения приведены относительно Release.75.

- Браузер переведён на единый встроенный движок Chromium на основе Electron: сайты открываются внутри SimplyOS, доступны скачивание и отправка файлов, история и новые вкладки. Исправлены переходы из поиска, меню Alt и выход из полноэкранного видео. Движок входит в подписанный пакет ОС.
- Предупреждения для HTTP-сайтов, ошибок сертификата и запросов камеры или микрофона оформлены средствами SimplyOS.
- При переключении пользователей через экран блокировки сохраняются окна и документы предыдущего пользователя; профили браузера разделены. Выход из профиля по-прежнему завершает сеанс.
- Переработан Магазин: витрина, категории, поиск, сортировка, страницы приложений и раздел обновлений. Иконки загружаются с сервера по адресам из подписанного каталога. Исправлены установка служб приложений и восстановление прерванной настройки dpkg.
- В Магазине доступны X и Telegram с отдельными профилями и системными уведомлениями. Свёрнутое окно остаётся в панели задач; закрытие переводит фоновое приложение в трей. Из трея можно развернуть или завершить приложение.
- Приложение itch.io получило подборки, обложки, поиск каталога, библиотеку и избранное. Исправлены скачивание, перенаправления, импорт и запуск HTML5-игр; добавлен ход установки. Убраны фиксированные ограничения размера. Установленные игры работают локально на отдельных адресах без доступа к системному API.
- В Магазине доступны «Торренты» на основе Transmission и «Удалённый рабочий стол» для локальной сети. Системные компоненты устанавливаются вместе с приложениями. Удалённый сеанс открывается в отдельном окне с полноэкранным просмотром; VeNCrypt TLS использует подтверждение и закрепление сертификата устройства.
- SimplyVPN адаптирован к узким окнам. Управление активным VPN объединено в одну плитку быстрых настроек, из уведомления убраны дублирующие кнопки.
- После перезагрузки сохраняются Wi-Fi, Bluetooth, яркость, громкость и отключение звука. Исправлены переключение раскладки, индикатор языка, значки громкости и быстродействие индикации клавиш Fn. Убрано повторное уведомление о снимке экрана; недоступная погода скрывается на экране блокировки.
- Исправлена работа Центра обновлений при большом каталоге резервных копий. Ошибки вспомогательных списков не скрывают обновления ОС.
- App API 1.12 включает возможности официальных веб-клиентов, itch.io, торрент-службы и удалённого рабочего стола. Приложения Магазина обновляются отдельно от ОС.
- Установщик автоматически выбирает загрузчик для UEFI или BIOS и проверяет пакеты зеркала до очистки диска. В виртуальных машинах включается совместимый программный рендерер, без требования 3D-ускорения. Шифрование LUKS2 остаётся необязательным.

## 26.10-Dev.97

- Исправлен запуск установленных HTML5-игр itch.io: адрес изолированной игровой страницы больше не заменяется адресом оболочки. Игры сохраняют доступ к ресурсам движка и не получают системный мост приложений.
- Иконки Магазина загружаются с сервера по адресам из подписанного каталога. Исправлены иконки «Торрентов» и «Удалённого рабочего стола»; «Торренты» используют оригинальную иконку Transmission.
- Исправлена ошибка netlink при включении входящего удалённого доступа и ограничения, мешавшие загрузке встроенного VNC-клиента. Добавлен адаптер VeNCrypt TLS с подтверждением и закреплением сертификата устройства.
- Удалённый сеанс открывается в отдельном системном окне с полноэкранным просмотром. Активные подключения не сохраняются в рабочих пространствах и при перезапуске.
- В Магазине опубликованы «Торренты» и «Удалённый рабочий стол» 1.0.2 с обновлёнными интерфейсами и отображением выполнения операций. В «Торрентах» появились фильтры и сводка скорости загрузки и отдачи.

## 26.10-Dev.96

- Исправлена установка системных компонентов приложений «Торренты» и «Удалённый рабочий стол» после прерванной операции dpkg. Магазин завершает настройку пакетов и проверяет зависимости в отдельной системной задаче.
- Если пакет приложения установлен, а системные компоненты отсутствуют, их можно восстановить из Магазина.

## 26.10-Dev.95

- Для «Торрентов» и «Удалённого рабочего стола» добавлены собственные иконки в Магазине.
- Необходимые системные пакеты и службы устанавливаются вместе с приложениями. Отдельные кнопки установки компонентов внутри приложений убраны.
- Исправлена ошибка «Неизвестная системная операция» при запуске и остановке служб этих приложений.

## 26.10-Dev.94

- После перезагрузки сохраняются состояния Wi-Fi и Bluetooth, яркость, громкость и отключение звука. Настройки звука учитывают учётную запись пользователя.
- Установка HTML5-игры itch.io показывает ход скачивания и распаковки после ввода пароля. В браузере появился индикатор загрузки файлов.
- Для HTTP-сайтов и ошибок сертификата браузер показывает предупреждение SimplyOS с подтверждением перехода. Запросы доступа сайтов к камере, микрофону и другим возможностям оформлены в интерфейсе системы.
- Убрано повторное уведомление о снимке экрана; выровнена панель фоновых приложений.
- App API 1.12 добавляет операции для официальных приложений удалённого рабочего стола и торрент-клиента. Оба приложения опубликованы отдельно в Магазине и требуют Dev.94.
## 26.10-Dev.93

- Для установленных HTML5-игр исправлена политика загрузки ресурсов движка. Системный мост больше не внедряется в изолированную страницу игры; сама игра по-прежнему не получает доступ к системному API.
- В настройках и быстрых настройках значки громкости выводятся SVG-файлами Material Design в том же элементе и размере, что и соседние значки.

## 26.10-Dev.92

- Исправлена ошибка HTTP 500 при открытии Магазина после Dev.91: обработчик каталога установленных приложений больше не требует контекст HTTP-запроса при внутреннем вызове Магазином.
- В настройках и быстрых настройках выровнены иконки звука Material Design, в том числе в узком окне.
- Проверены сборка интерфейса, состав и подпись пакета; обновление опубликовано в канале Dev.

## 26.10-Dev.91

- Исправлен запуск установленных HTML5-игр itch.io: собственные скрипты и ресурсы игры открываются на отдельном локальном адресе, изолированном от API оболочки. Ранее часть игр оставалась на чёрном экране.
- itch.io обновлён до 1.1.4. В пакет игры сохраняется обложка, а при её отсутствии показывается иконка геймпада. Импорт принимает ZIP с несколькими `index.html`, собственным `manifest.json` и одиночные HTML-файлы. Расширена проверка адресов зеркал itch.io без передачи OAuth-токена на CDN.
- Иконки громкости заменены на Material Design. Индикаторы громкости и яркости быстрее реагируют на клавиши Fn и показываются поверх видео в полноэкранном режиме.
- Когда погода недоступна, на экране блокировки её блок скрыт; в центре уведомлений остаётся сообщение о недоступности.
- Проверены сборка интерфейса, 13 тестов клиента itch.io, состав пакетов, подписи каталогов и публикация через HTTPS. Запуск конкретных игр на тестовом устройстве остаётся для проверки после установки обновления.

## 26.10-Dev.90

- Убраны фиксированные ограничения размера приложений и игр itch.io. Загрузка больших пакетов идёт через временные файлы; перед установкой проверяются подпись каталога, контрольная сумма пакета и доступное место на диске.
- itch.io обновлён до 1.1.3. Загрузка HTML5-игр больше не останавливается на 50 МБ.
- Исправлено переключение раскладки кнопкой трея: команда передаётся через системный ввод клавиатуры. Индикатор уточняет язык по вводу в окнах приложений и встроенном браузере. Список раскладок в настройках применяется к Wayland-сессии.
- Свёрнутые Telegram и другие фоновые веб-приложения остаются в панели открытых окон. После нажатия на закрытие окна они переходят в трей; оттуда их можно открыть или завершить.
- Проверены сборка интерфейса, загрузка файла больше прежнего лимита, переключение раскладки на тестовой системе и целостность подписанных пакетов.

## 26.10-Dev.89

- Исправлен цвет названий приложений и текста витрины Магазина при совместной работе с общими стилями оболочки в светлой и тёмной темах.
- Из постоянного уведомления VPN убраны кнопки. Управление сохранено в быстрых настройках и трее.
- SimplyVPN 1.3.6 адаптирован к узким окнам и половине экрана: панель подключения, подписки, список серверов и диалоги.
- itch.io 1.1.2 поддерживает конкретное зеркало itch.io на Cloudflare R2. Другие хранилища провайдера не разрешаются автоматически; секретные параметры ссылки не выводятся в сообщении об ошибке.
- Проверены читаемость названий с полными стилями оболочки, VPN на ширинах 320–960 пикселей, отсутствие кнопок в уведомлении и ограничения адресов скачивания.
